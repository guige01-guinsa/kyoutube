# Recipe Scout v87 출시 준비 (1.0.1+87)

## 포함되는 변경

- 관리자 홈에 상품 등록·공개 도우미 추가. 초안을 먼저 표시하고 상품별 미완료 확인 항목을 안내합니다.
- 상품별 실제 노출 확인. 회원용 조회를 사용하며 현재 기기에 공개된 유효한 상품만 표시합니다.
- 구매처 검색어 변경 시 제휴 상품 갱신, 조회 실패 시 다시 불러오기.
- 쿠팡 수수료 안내를 상품명보다 앞에 배치.
- 기존 발급 링크 등록·검토·공개·쿠팡 이동 기능 유지. 앱에서 결제하지 않습니다.

## 쿠팡 연동 범위

수동 링크 등록은 기존 상품 관리 서버를 사용합니다. 관리자용 쿠팡 API 검색·링크 생성 화면은 포함되지만 API 키 발급·서버 설정·함수/신규 마이그레이션 적용과 실제 호출 검증은 별도입니다. 이번 Android 빌드에서 서버를 배포하지 않습니다. API의 시간당 호출 한도 보완도 서버 운영 적용 전에 필요합니다. 쿠팡 최종 승인이나 수수료 지급을 보장하지 않습니다.

## 업로드 후 남은 확인

1. Play Console에서 기존보다 높은 versionCode인지 확인하고 테스트 트랙에 업로드합니다. 이 작업에서 Console 업로드·출시는 실행하지 않습니다.
2. 동일한 테스트 트랙 파일을 휴대폰에 업데이트하여 로그인·레시피·장보기 기존 데이터 유지 여부를 확인합니다. 서명이 다르면 기존 앱을 삭제해 강제 설치하지 않습니다.
3. 관리자 인증 → 도우미 → 진간장 → 실제 노출 확인 → 수수료 안내·규격·쿠팡에서 구매 → 쿠팡 상품 연결을 확인합니다.
4. 일반 계정의 관리자 접근 차단, 미공개·만료 상품 숨김, 느린 네트워크 재시도를 확인합니다.
5. Play Console의 앱 액세스·광고 포함 여부·Data safety·콘텐츠 등급·대상 국가·심사 경고를 실제 운영 상태에 맞춰 점검합니다. 기존 자료의 과거 완료 기록을 현재 승인으로 간주하지 않습니다.
6. 실제 활동 화면을 촬영한 후 별도로 쿠팡 파트너스에 등록합니다. 현재 제출용 촬영은 미완료입니다.
