# 레시피 스카우트 1.0.1+51

영어 앱에서 YouTube 영상으로 영어 레시피 초안을 생성할 수 있도록 지원합니다.

- 앱 언어에 따라 `outputLocale`을 `en-US` 또는 `ko-KR`로 전달합니다.
- 영어 제목을 최대 80자까지 보존하고 영어 재료 단위와 조리 시간 표시를 지원합니다.
- 영어 설명의 광고·협찬 문구를 걸러내고 영어 작성 지시문을 적용합니다.
- 한국어 기본 동작과 레시피 성공 기준, 사용 횟수 정책은 유지합니다.

## 검증 및 배포

- Flutter 정적 분석 및 전체 154개 테스트 통과.
- YouTube AI 서버 로컬 테스트 26개, 타입 검사 및 형식 검사 통과.
- 2026-09-12 운영 `ai_youtube_recipe_assistant` 함수 버전 24 배포 완료, `ACTIVE` 및 JWT 검증 활성 상태 확인.
- 실제 로그인 계정으로 영어 초안을 생성하는 단말 종단 간 검증은 별도로 필요합니다. 서버 테스트는 모델 응답을 모의 처리합니다.
- AAB 배포 전 해당 서버 업데이트가 적용되어 있어야 합니다.

산출물 및 서명·해시 기록은 `release/recipe-scout-v51.aab`와 `release/recipe-scout-v51.aab.provenance.json`을 확인합니다.
