# 구매 품명 검색과 일반 쿠팡 구매 경로

운영 반영 완료: [v93 배포 기록](release-v93.md). 아래 개발 단계 기록 이후 DB·웹·AAB 적용과 출시 검증을 완료했다.

2026-09-30 개발 변경. 운영 DB·웹·AAB에는 아직 반영하지 않았다. 기존 v92 배포 파일은 유지한다.

## 사용자 흐름

구매 품명의 일부를 입력하면 300ms 후 후보를 조회한다. `돼지`, `앞다리살`, `돼지고기앞다리살`, `앞다리 돼지`로 관련 품명을 찾을 수 있다. 후보를 누르면 정확한 품명만 입력된다. 수량·단위는 자동으로 추정하거나 합치지 않는다. 기존 제휴 상품 선택이 있는 품명을 바꾸면 이전과 같이 선택을 해제한다.

후보는 한 번에 5개씩 표시하며 이전·다음 결과로 계속 조회한다. 정확히 일치하는 품명이 먼저 나온다. 후보가 없거나 조회가 실패해도 직접 입력할 수 있다. 검색 아이콘으로 현재 이름을 다시 조회할 수도 있다.

- 업소 구매·입고 입력: 공개 쿠팡 재료명·별칭과 현재 업소의 활성 공급업체 취급상품에서 조회한다.
- 개인 장보기의 재료 직접 추가, 구매처 찾기: 공개 쿠팡 재료명·별칭에서 조회한다.
- 후보 검색에는 상품명·브랜드·규격도 사용한다. 인터넷 전체 상품을 가져오는 기능은 아니다.
- 업소 거래처·상품 선택, 취급상품 목록, 구매 재료 검토, 개인 구매요청 단계별 목록에는 띄어쓰기 무시·여러 단어 검색을 적용했다. 검색 키는 표시용이며 재료 병합이나 재고 식별에 사용하지 않는다.
- 제휴 상품 관리와 공급업체 공개 검색은 기존에도 부분 검색을 지원하므로 해당 조회 로직은 유지했다.

## 제휴 상품이 없는 경우

개인 구매 준비와 구매처 찾기에는 `쿠팡에서 다른 상품 찾기`를 표시한다. 검색 URL에는 입력한 재료명만 보내며 계정·업소·요청서 정보는 보내지 않는다. 일반 검색은 제휴 링크가 아니고, 상품·주문·입고 기록을 자동 생성하지 않는다. 사용자는 판매 규격을 확인하고 돌아와 기존 구매 기록 기능으로 실제 수량을 기록한다.

업소에서는 요청서 승인 후 쿠팡 상품 확인 화면에서 일반 검색을 사용할 수 있다. 기존의 중복 주문 확인을 거치며, 열기 직전에 최신 권한·승인 상태·요청서 변경 여부를 재확인한다. 연습 업소·미승인·완료 요청은 차단한다. 승인된 제휴 상품 계획이 바뀐 경우 일반 검색으로 우회하지 않고 수정·재승인을 안내한다.

## 데이터와 배포

새 읽기 전용 함수 `search_purchase_names`를 [0082 마이그레이션](../supabase/migrations/0082_purchase_name_search.sql)에 추가했다. 기존 `find_shopping_affiliates_v2`의 정확한 재료명 검증과 수량·규격·승인 검증은 변경하지 않았다. 검색 후보에 전체 공개 범위가 적용되며 숨김·삭제·만료·다른 표면의 상품을 제외한다. 업소 상품은 `business_can(..., 'purchasing.read')`로 권한을 확인하고 해당 업소에 한정한다. 비활성 공급업체와 상품은 제외한다.

운영 반영 시 0082를 먼저 적용한 뒤 웹·앱을 배포해야 한다. 이전 앱은 새 함수에 의존하지 않는다. 새 앱에서 서버 함수가 아직 없거나 조회에 실패하면 직접 입력 및 기존 구매 흐름을 유지하고 재시도를 안내한다. 별도 API 키는 필요하지 않다.

## 검증 기록

- 검색 DB 독립 검사: 부분·다중 단어·공백·페이지·정확 일치 우선·특수문자·공개 범위·권한·업소 분리 27개 통과.
- 실제 업소 스키마와 권한 함수를 포함한 격리 DB 검사: 312개 통과, 운영 자료 변경 0건.
- 관련 앱 테스트: 61개 통과. 늦은 검색 응답, 계정 변경, 직접 입력, 페이지 선택, 320px·2배 글자, 일반 검색의 승인 재확인과 비기록 동작 포함.
- 최종 정적 분석은 문제 없이 통과했다. 전체 앱 검사에서는 802개 통과·4개 제외·번역 목록 검사 1개 실패였다. 누락된 16개 번역 항목을 보완하고 해당 파일의 3개 검사를 모두 재통과했다. 재검사를 포함해 실행 대상 803개를 확인했다. 전체 실행은 `.artifacts/purchase-search/verify.log`, 재검사는 `localization.log`, 요약은 `result.json`에 기록했다.
- 환경 진단에는 기존 Android 라이선스 상태 확인 및 Windows 데스크톱용 Visual Studio 경고가 남아 있다. Flutter 3.44.8과 JDK 17을 사용했으며 이번에는 출시 빌드를 실행하지 않았다.

실제 쿠팡 주문·결제는 테스트하지 않았다.
