# 레시피 스카우트 v79 — 통합 업무 개편 운영 배포

2026-09-22, 사용자 승인으로 기존 1~3차 개편, 담당자 프로필 관리와 메뉴 후보·승인·빠른 구매 기능을 운영 DB/웹에 반영하고 **1.0.1+79 서명 AAB**를 생성했다.

## 제공하는 업무 흐름

- 일반 사용자, 업소/전문가, 공급업체의 영역과 업소 공동 업무 동선을 구분한다. 화면에서 선택하는 역할은 서버 접근 권한을 늘리지 않는다.
- 공동 레시피에서 특정 버전을 **메뉴 후보**로 등록할 수 있다. 후보는 개발 중인 레시피와 가격 미정 상태를 허용한다. 시험 조리·승인된 버전과 확정 판매가를 갖춘 뒤 출시 준비/판매로 전환한다.
- 사장은 재무 권한과 별개인 **메뉴 선정·출시·가격 관리** 권한을 위임할 수 있다. 기존 메뉴 관리자의 권한은 이력과 함께 이전한다. 판매 메뉴는 레시피의 새 버전으로 자동 교체되지 않는다.
- **판매 메뉴로 빠른 구매**에서 메뉴·인분·납품일을 선택하면 같은 재료를 합산한다. 처음에는 업체·상품·단위 환산을 확인하고 저장하며, 다음 작성부터 재사용한다. 업체별 구매 초안과 사용할 재고 예약은 한 번에 저장한다.
- 계획 저장/불러오기와 최근 작업을 제공한다. 진행 중 구매요청 수를 확인하고, 필요한 경우 기존 요청을 열어 조정한다. 자동 발주나 공급업체 메시지 발송은 하지 않는다.
- 공동 거래처·상품 규격, 품목별 부분 입고·반품·마감, 재고 수불·예약·실제 사용, 사장의 담당자 프로필 관리를 함께 반영했다.

사용법: [빠른 구매와 메뉴 선정](business-menu-fast-purchase.md), [공동 거래처](business-shared-suppliers.md), [입고·재고](business-inventory.md), [담당자 관리](business-staff-management.md), [사용자 영역 개편](workspace-reorganization.md).

## 배포 및 산출물

- 운영 웹: https://recipe-scout-workspace.web.app/#/workspace
- Android: [recipe-scout-v79.aab](../release/recipe-scout-v79.aab), 78,946,548 bytes, package `com.kyoutube.app`, versionName `1.0.1`, versionCode `79`, production 설정.
- SHA-256: `88142650997ABBBADE3A7C54FC6CE75A5F58479C110700971C69562EFCB0D15F`. 기존 v78 업로드 서명과 일치하며 v78 AAB는 보존했다.
- 운영 DB는 **0064, 0068, 0069, 0070**만 검토 후 한 트랜잭션으로 적용했다. 기존 함수 정의/권한/마이그레이션 이력과 주요 행 수를 사전에 보관하고, 동시 변경 여부를 검사했다. 이는 전체 DB 데이터 백업이 아니다. 관련 없는 보류 마이그레이션을 일괄 적용하지 않았다.
- Edge Function, 프로젝트 설정, 서명 키는 변경하지 않았다. 이번 기능은 새 AI 호출이나 외부 유료 API를 추가하지 않는다. 저장되는 업무 데이터에 따른 기존 DB/저장소 사용량은 늘 수 있다.

## 적용 범위와 남은 확인

- **Google Play 업로드와 실제 휴대폰 설치는 수행하지 않았다.** AAB 생성·검증까지 완료했다.
- 실제 직원의 로그인/MFA 이후 화면 전체를 운영 계정으로 조작한 검사는 하지 않았다. 권한 처리는 격리 DB·운영 롤백 검사와 UI 테스트로 검증했고, 운영 브라우저에서는 공개/게스트 화면과 로그인 보호를 확인했다. 부하 시험이나 전체 시스템 침투 시험을 수행했다는 의미는 아니다.
- 재료별 기본 구매처는 한 곳이다. 상품이나 환산이 바뀌면 담당자가 재확인한다. 입고 예정량은 빠른 구매에서 자동 차감하지 않는다.
- 구매요청을 취소/수정해도 조리용 재고 예약은 자동 해제되지 않는다. 재고·조리 예약 화면에서 실제 사용 또는 해제를 기록한다.
- 기존 Android에서는 후보가 출시 준비/0원으로 표시될 수 있다. 판매 메뉴로 노출되지 않으며 미승인 후보의 출시 구매는 서버에서 차단한다. 새 후보/가격 미정/빠른 구매 화면은 v79 앱 또는 최신 운영 웹에서 사용한다.
