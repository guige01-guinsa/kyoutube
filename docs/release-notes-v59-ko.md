# v59 보안 보강

버전: 1.0.1+59. 패키지: com.kyoutube.app. Google Play 게시 전 상태.

- 개인 레시피 기본 비공개, 비공개 이미지 인증 표시.
- 계정 전환 시 개인 데이터 캐시 분리 및 로그아웃 시 편집 화면 종료.
- 무료 인분 환산·레시피 버전 유지, 원가·판매가·매출은 서버 유료 권한으로 보호.
- 계정 관리의 2단계 인증 등록 화면과 관리자 화면의 인증 안내.
- Firebase 초기화 제한 및 Android 로그인/캐시 백업 제외.

Flutter 정적 분석 통과, 전체 220개 테스트 통과·선택 캡처 4개 생략. 서버 62개 테스트와 로컬 DB 권한 계약 통과. AAB 무결성 및 v58과 동일한 업로드 서명 확인.

운영 DB 0042–0046 및 함수 5개는 배포했다. 관리자 MFA 강제 0047·0048은 본인 등록 후 적용한다. Google 결제/푸시 서버 계정 및 유출 비밀번호 보호·전체 인증 복구는 아직 완료되지 않았다.

USB 휴대폰은 Play 설치본 v58이므로 로컬 APK 서명으로 덮어쓰지 못했다. 기존 앱과 데이터는 보존했다. AAB를 Play 테스트 트랙에 배포한 후 휴대폰에서 업데이트해야 한다.

상세 상태와 필요한 후속 작업은 [보안 운영 반영 기록](security-rollout-2026-09-13.md)을 따른다.
