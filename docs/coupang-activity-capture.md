# 쿠팡 앱 활동 화면 촬영

2026-09-26 확인 상태: Android 연결, 앱 관리자 인증 및 쿠팡 로그인을 완료했습니다. 설치 앱은 1.0.1(86)입니다. 등록 상품 100개 중 진간장(001)의 연결 상품을 쿠팡에서 삼화식품 진간장 1.8L, 1개로 직접 확인했습니다. 규격과 확인 기록을 입력하고 이 상품 한 개를 모바일 공개로 저장했습니다. 웹 공개는 선택하지 않았습니다. 확인 기록에 앱 등록 근거와 최종 계정 승인 대기 상태를 구분했습니다. 현재 계정의 잔치국수 장보기에서 구매처 검색어를 진간장으로 변경했지만 설치 앱의 제휴 상품 표시가 갱신되지 않았습니다. 소스에는 현재 검색어를 사용하는 수정이 있으나 기기에 반영되지 않았습니다. 제출용 활동 화면은 아직 촬영하지 않았으며 점검용 이미지는 제출 증빙이 아닙니다.

## 촬영할 화면

휴대폰의 레시피 스카우트 → 장보기 도우미 → 실제 등록된 재료의 구매처 찾기 → 공개된 쿠팡 제휴 상품.

한 화면에 수수료 고지, 실제 상품명·규격, **쿠팡에서 구매** 버튼이 읽히도록 스크롤합니다. 개인 계정 정보나 다른 알림이 겹치지 않는 화면을 촬영합니다. 스토어 소개 이미지나 관리자 편집기 대신 회원이 보는 상품 화면을 사용합니다.

상품이 표시되지 않으면 관리자 제휴 상품 관리에서 실제 발급 링크를 등록하고 상품·규격·재료 별칭과 모바일 게시 조건을 확인해야 합니다. 기존 100개 자료는 검토용 자료이며 자동으로 공개하거나 확인된 상품이라고 표시하지 않습니다. 이 촬영 준비 작업에서 직접 확인한 진간장(001) 한 개를 모바일에 공개했습니다. 나머지 상품은 일괄 공개하지 않았습니다.

수수료 고지는 개발 소스에서 상품명 위로 이동했습니다. 설치된 앱에 이 수정이 반영되었는지는 별도 확인이 필요합니다.

## 원본 캡처

휴대폰 자체 스크린샷 기능을 쓰거나, USB 디버깅 연결을 본인이 허용한 Android 기기에서 해당 화면을 연 뒤 아래 도구를 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/dev/capture-coupang-activity.ps1
```

연결된 기기가 하나인지 확인하고, 현재 열린 앱이 `com.kyoutube.app`인 경우에만 원본 PNG를 저장합니다. 결과 위치는 `.artifacts/coupang-activity/`입니다. 여러 기기를 연결했다면 `-Device`로 대상 기기를 지정합니다. 휴대폰에도 같은 원본 파일이 남습니다.

실제 화면의 내용을 확인한 뒤 쿠팡 파트너스 **내 정보 → 모바일 앱 목록 → 스크린샷**에 등록합니다. 촬영 도구는 업로드하지 않습니다. 테스트 데이터로 렌더링한 이미지나 합성 이미지는 실제 활동 증빙으로 사용하지 않습니다.
