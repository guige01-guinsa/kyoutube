# 레시피 스카우트 v80 — 레시피 수집과 이름별 레시피 공간

사용자 승인으로 **1.0.1+80** 운영 웹 배포와 서명 AAB 생성을 완료했다. 웹 배포 완료: 2026-09-23 08:04 KST.

## 변경 내용

- 일반 사용자와 업소·전문가 메뉴에 **레시피 수집**을 제공한다.
- 개인 목록은 **사용자명님 레시피**, 업소 목록은 **업소명 레시피**로 표시한다. 이름이 없으면 개인/업소 레시피로 표시하며 이메일이나 계정 ID를 대신 표시하지 않는다.
- 업소 수집 화면에서 개인 수집·검토 후 업소로 가져오는 흐름을 제공한다. 가져오기 직전에 대상 업소·공유 범위를 확인하고 쓰기 권한을 다시 조회한다.
- 개인 원본과 사진은 그대로 유지한다. 업소에는 기존 API로 재료·조리법·팁의 검토용 사본을 만들며, 판매 메뉴 승인은 별도다.
- 계정 전환 중 이전 사용자 이름을 표시하지 않으며 공유 확인 대화를 취소한다.

자세한 사용 흐름: [레시피 수집과 이름별 공간](recipe-collection-workspaces.md).

## 범위와 남은 확인

- DB 마이그레이션, Edge Function, 운영 프로젝트 설정, 서명 키는 변경하지 않았다.
- **Google Play 업로드와 실제 휴대폰 설치는 수행하지 않았다.** AAB 생성·검증까지 완료했다.
- 실제 직원 로그인 이후 사용자명·업소명과 복사 동작은 운영 계정으로 수행하지 않았다. 계정 이름, 계정 전환, 권한 철회와 공유 확인은 위젯 테스트로 검증했고 기존 서버 접근 검사를 사용한다.
- 기존 v79에도 있던 Cupertino 아이콘 글꼴 경고가 빌드에 표시됐다. 앱 코드에는 해당 아이콘을 직접 참조하는 부분이 없으며 이번 빌드와 화면 검사는 통과했다.
