# 월간 프리미엄 영상 분석 — 구현 및 비용 검토

2026-09-13. 코드와 DB 0050 초안 구현. 사용자가 저장한 로컬 키 인증을 확인하고 실제 Gemini 호출을 수행했다. 새 사용자에게 2.5 Flash 생성이 차단되는 오류를 확인해 3.6 Flash로 연결을 수정했다. 사용자의 추가 승인에 따라 운영 키 등록·DB 0050·새 함수 배포와 v61 서명 AAB 생성을 완료했다. [v61 배포 기록](release-v61.md)에 적용 상태와 검증 범위를 기록했다.

## 사용자 기능

초안 화면에서 사용자가 방식을 선택한 뒤 생성을 시작한다. 화면 진입만으로 기존 방식이 먼저 실행되어 비용이 발생하지 않도록 했다.

1. **기존 자동 초안 만들기**: 제목·설명 기반 기존 생성 경로. 자막·힌트로 보완하는 기능도 유지한다.
2. **영상 분석으로 초안 만들기**: 월간 프리미엄(`paid_monthly`)만 사용한다. 무료·연간 베이직·만료 회원은 사용할 수 없다. 구독을 취소했더라도 기존 정책상 만료 전 유효한 이용 기간은 인정한다.
3. **확인 필요 표시**: 영상 분석에서 분량·시간·인분의 근거가 없으면 구조화된 값을 비우고 미확인 재료/단계에 한글·영어 확인 표시를 붙인다. 근거 위치는 모델이 제시한 정보이며 독립적인 사실 검증 결과가 아니다. 조리 문장과 영상의 실제 일치는 사람이 확인해야 한다.

사용자가 선택한 한도는 **한국 시간 기준 월 20회, 영상당 최대 20분**이다. 서버가 YouTube API로 실제 공개 상태와 길이를 다시 확인한다. 비공개·일부 공개·라이브·길이 미확인 영상은 제외한다.

- 영상 분석이 시작되면 월 영상 분석 횟수에 포함된다. 시간 초과나 불완전 결과도 제공사 비용이 발생할 수 있어 자동 재시도하지 않는다.
- 초안 생성 성공 시 기존 전체 AI 일/주/월 한도에도 1회 포함된다. 기존 설명 기반 생성의 정책값은 바꾸지 않았다.
- 키 누락, 권한/한도 차단, 영상 사전검사 실패는 영상 분석 20회에 포함되지 않는다.
- 앱은 사용 횟수와 분석 전용 안내를 표시한다. 회원·사용 내역 조회 실패 시 영상 분석 버튼을 잠그고 기존 자동 초안은 계속 제공한다.

## 구현

- 새 Edge Function: `ai_youtube_video_assistant`. 고정 모델 `gemini-3.6-flash`에 공개 영상 URL을 직접 전달한다. YouTube 앱의 ‘동영상을 요약해 줘’를 읽거나 실행하는 방식은 아니다.
- 새 DB: `0050_premium_video_analysis.sql`. 예약 시 서버 월간 프리미엄 확인, 월 20회 제한, 기존 동시 요청/단기 빈도 제한을 적용한다. 회원은 자신의 집계만 읽고 예약·분석 시작은 service role만 실행한다.
- 본문 64 KiB, YouTube 조회 12초, Gemini 호출 90초, 출력 상한 8,192 토큰(생각 포함), 생각 수준 `low`. 앱 요청 대기 상한 180초. 설정이 없으면 기존 방식으로 몰래 전환하지 않고 준비 중 오류를 반환한다.
- 응답 JSON 스키마로 단일 레시피 객체를 요구한다. JSON MIME만 지정했을 때 배열이 반환되는 실제 실패를 보완했다. 중첩 스키마의 `maxItems`가 400 오류를 일으켜 API 스키마에서는 제외하고 서버의 기존 재료 60개·단계 40개 제한은 유지한다.
- API 키는 서버에만 두며 앱에 포함하지 않는다. 클라이언트가 보낸 설명·채널·길이를 영상 분석의 근거로 신뢰하지 않고 서버 메타데이터와 영상 URL을 사용한다.
- API 모델/입출력 토큰·생각 토큰·입력 모달리티·영상 길이를 기존 사용 예약에 기록한다. 실패했어도 사용량을 보존하며, 반환받지 못한 사용량은 `usageKnown=false`로 남긴다. 기존 운영 관측에서는 YouTube AI 범주에 집계한다.

## 대략적인 비용 — 3.6 Flash 기준으로 수정

**이전 2.5 Flash 예상액은 이번 키의 운영 예산으로 사용하면 안 된다.** 실제 생성 응답이 새 사용자에게 해당 모델을 제공하지 않는다고 안내했다. 3.6 Flash는 영상 입력과 구조화 출력을 지원하는 안정 모델이다. [모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.6-flash)

Gemini 3.6 Flash Standard 일반 유료 요금은 2026-12-31까지 입력 **$0.75/백만 토큰**, 출력(생각 포함) **$3.75/백만 토큰**이다. 공시 요금은 2027-01-01부터 각각 **$1.50/$7.50**로 2배가 된다. [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.6-flash)

YouTube URL 무료 미리보기 혜택은 예산에 반영하지 않았다. 정적 영상의 1 FPS, 프레임 초당 66~258토큰과 음성 초당 32토큰, 요청문 1,500토큰, 출력·생각 합계 4,000토큰을 가정했다. 실제 프레임 처리와 토큰은 영상에 따라 달라진다. [영상 입력 안내](https://ai.google.dev/gemini-api/docs/generate-content/video-understanding)

**환율 1달러=1,400원 가정**(실시간 환율 아님). 권장 범위는 출력 증가와 여유분을 포함하며 실제 청구액이 아니다. 부가세·환전 수수료·Supabase 등 기존 서버비·기존 OpenAI 사용료는 별도다.

| 영상 길이 | 2026년 운영 예산/회 | 2027년 공시 요금 적용 시/회 |
|---|---:|---:|
| 5분 | 약 **60~140원** | 약 **120~280원** |
| 10분 | 약 **90~240원** | 약 **180~480원** |
| 20분 | 약 **150~420원** | 약 **300~840원** |

10분 영상 기준 2026년 예산:

| 사용 규모 | 월 분석 횟수 | 추가 영상 AI 예산 |
|---|---:|---:|
| 회원 1명, 월 20회 사용 | 20회 | 약 **1,800~4,800원** |
| 월간 프리미엄 2,000명, 평균 5회 사용 | 10,000회 | 약 **90만~240만원** |
| 월간 프리미엄 2,000명, 모두 20회 사용 | 40,000회 | 약 **360만~960만원** |

요금 인상 시 같은 사용량 예산은 2배다. 20분 영상을 2,000명이 모두 월 20회 사용하는 극단값은 2026년 약 600만~1,680만원이다. 원시 계산: `.artifacts/video-analysis-cost-estimate.json`. 실제 청구는 프로젝트 사용량·요금 화면에서 확인해야 한다.

## 실제 사용을 위한 다음 단계

1. 키 생성 및 로컬 파일 저장은 완료했다. Git 제외와 공식 API 인증을 확인했으며 키를 출력하거나 앱에 복사하지 않았다. 프로젝트별 사용 한도와 결제 설정 변경은 하지 않았다.
2. 서버 `GEMINI_API_KEY` 등록은 완료했다. 필요하면 로컬 `.env.gemini.local`에 보관하고 파일 경로만 전달한다. 해당 파일은 `.env.*` 규칙으로 Git에서 제외된다. 앱의 `.env.production`이나 AAB에는 Gemini 키를 넣지 않는다.
3. 직접 제공사 호출 시험과 운영의 인증·영상 메타데이터 조회·사용량 기록을 구분한다. 실제 영상 시험 결과는 아래에 기록한다. 운영 연결 후 관리자 테스트 계정으로 전체 경로를 검증하고 대표 표본을 늘린다.
4. 후속 명시적 승인으로 0050과 새 함수 1개 배포, `VIDEO_ANALYSIS_ENABLED=true` 활성화, v61 AAB 생성을 완료했다. 미적용 0047·0048은 함께 적용하지 않았다.

[AGENTS.md](../AGENTS.md)는 운영 마이그레이션·함수 배포·릴리스 빌드에 명시적 승인을 요구한다. 이번에는 사용자의 명시적 운영 승인 후 키 등록·0050·새 함수·v61 AAB를 적용했다. 결제 설정 변경은 실행하지 않았다.

## 키 등록 후 실제 시험 결과

- 로컬 키의 파일 형식, Git 제외, Google 모델 조회 인증(HTTP 200)을 확인했다. 모델 조회 성공만으로 생성 접근까지 보장되지 않아 실제 요청을 별도로 확인했다.
- 2.5 Flash 영상 및 최소 텍스트 생성은 HTTP 404였다. Google 응답은 새 사용자 사용 불가와 3.6 Flash 사용을 안내했다. 키를 재발급하거나 결제를 바꾸지 않고 연결 모델을 수정했다.
- 3.6 Flash에 JSON MIME만 지정한 첫 시험에서는 레시피 배열이 반환됐다. 단일 객체 스키마를 추가했고, 중첩 스키마의 배열 `maxItems`로 인한 HTTP 400을 최소 텍스트 비교 시험으로 분리해 수정했다. 서버의 결과 크기 제한은 유지한다.
- 첫 영어 비빔밥 영상은 공개 페이지 길이 확인에서 1,421초로 확인돼 월간 프리미엄의 20분 조건에 맞는 최종 표본에서 제외했다. 시험 도구도 이후 공개 페이지 메타데이터의 ID·공개 상태·라이브 여부·길이 확인 없이는 실행하지 않도록 보강했다. 운영 함수는 별도로 YouTube Data API를 통한 사전검사를 수행한다.

| 최종 적격 표본 | 영상 길이 | 생성 지연 | 유료 요금 환산/회 |
|---|---:|---:|---:|
| 한국어 참치비빔밥 (`p0JEtaprf2c`) | 4분 13초 | 11.118초 | 약 35.4원 |
| 영어 불고기 (`3qBjL_HGvco`) | 9분 59초 | 23.442초 | 약 68.0원 |

비용은 응답의 실제 입력·출력·생각 토큰과 2026년 Standard 요금, 환율 1,400원 가정으로 환산한 값이다. 청구서 확인 결과가 아니며 무료 구간과 세금은 반영하지 않았다. 소수 예제의 비용을 모든 영상의 평균으로 취급하면 안 된다.

직접 제공사 시험은 운영에서 사용하는 동일한 요청 생성 코드를 사용한다. 인증·월 한도 DB·YouTube Data API를 포함한 운영 전체 경로의 성공을 의미하지 않는다. 실제 서버의 결과 검증도 두 표본 모두 통과했다(한국어 재료 13개·8단계, 영어 재료 14개·6단계). 캡처 결과를 실제 서버 검증 코드에 재입력한 결과는 `.artifacts/gemini-live-acceptance.json`에 보관한다. 증거 위치는 모델 자체 출력이므로 분량·불 세기·시간의 정확성이나 90% 성공률은 여전히 별도의 원본 대조 표본 검증이 필요하다.

재현 도구: `tools/test/gemini_live_smoke.ts`(외부 호출), `tools/test/gemini_validate_captured.ts`(저장된 결과의 오프라인 검증). 키는 `.env.gemini.local`에서 실행 중에만 읽으며 로그·소스·앱에 기록하지 않는다. 운영 배포·DB 0050 적용·v61 서명 AAB 생성은 후속 승인에 따라 완료했다. 운영 임시 계정·실제 사용량을 만드는 전체 경로 시험은 자동 승인 검토에서 별도 승인이 필요하다고 판단해 미실시 상태다.
