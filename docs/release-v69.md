# Recipe Scout v69 — 2026-09-16

사용자 승인으로 역할별 첫 화면·메뉴 개편을 **운영 웹과 1.0.1+69 서명 AAB**에 반영했다. DB와 서버 함수는 변경하지 않았다. 기존 v68 서명 인증서를 유지했다. Play 업로드와 휴대폰 설치는 수행하지 않았다.

## 사용 방법

처음 열 때 일반 사용자, 업소·전문가, 식자재 공급업체 중 이용 목적을 선택한다. `전체 메뉴 → 이용 목적 관리` 또는 `내 계정 → 이용 목적 관리`에서 여러 목적을 추가할 수 있다. 두 가지 이상을 선택하면 홈과 전체 메뉴의 목적 버튼에서 화면을 전환한다.

| 목적 | 주요 메뉴 |
|---|---|
| 일반 사용자 | 홈 / 검색 / 내 레시피 / 장보기 / 전체 메뉴 |
| 업소·전문가 | 홈 / 요청하기 / 거래처 / 셰프 / 전체 메뉴 |
| 식자재 공급업체 | 홈 / 업체·상품 / 공급업체 찾기 / 전체 메뉴 |

기존 계정의 레시피·장보기·거래처·구매요청 자료는 함께 사용한다. 목적 선택은 화면 설정이며 구독·권한을 변경하지 않는다. 회원 설정은 같은 계정으로 앱과 웹에서 불러오며, 비회원 설정은 해당 브라우저/기기에만 저장한다. [상세 변경 범위](role-based-workspaces.md).
