## 반영 내용

장보기 재료 카드에 공개된 쿠팡 상품을 표시하고, 검증한 판매 옵션에 따른 구매 수량·총량·여유량을 계산한다. 공급업체 구매는 기존 방식을 유지하며 업소의 쿠팡 구매 링크는 기존 승인 절차를 따른다. 관리 대상의 수정·영구 삭제·단위 변경을 포함한 이전 개편도 함께 반영했다.

DB 변경 0076~0081을 한 트랜잭션으로 적용했다. 기존 87개 테이블의 자료 건수가 변경되지 않았음을 트랜잭션 안에서 확인했다. 영구 삭제 기능을 적용했지만 배포 과정에서 사용자의 실제 기록을 삭제하지 않았다. 기존 recipe_api는 배포본 6개 소스가 현재 코드와 일치하여 유지했다.

## 검증

- 소스 분석 통과, 전체 앱 테스트 792개 통과, 기존 제외 4개.
- 사전 격리 DB 검증 463개 통과.
- 운영 DB의 공개 RPC 8개·비공개 함수 5개·RLS 테이블 5개 권한 확인.
- 실제 PostgreSQL의 질량 환산·호환되지 않는 단위 거절·잘못된 포장 수 거절 및 비로그인 차단 확인.
- 실제 운영 REST API의 새 함수 3개 비로그인 차단 확인.
- 웹 빌드와 실제 제공 파일의 SHA-256 일치. 한영 데스크톱·모바일 및 로그인 보호 경로 확인.
- AAB의 최종 패키지·버전·서명·글꼴·아이콘·R8 자료·3개 CPU 아키텍처·운영 설정·민감 정보 비포함 검사 통과.

## 운영 시 확인할 점

배포 당시 공개 쿠팡 상품 101개 중 자동 계산용 구조화된 판매 규격은 0개였다. 관리자가 실제 판매 옵션을 확인하여 내용량·단위·포장 수·옵션명을 입력해야 수량 자동 계산이 작동한다. 상품명만 보고 중량을 추정하여 채우지는 않았다. 링크 열기는 결제나 입고를 자동으로 완료하지 않는다.

실제 Google Play 설치와 휴대폰 주문·결제는 이번 검증에 포함하지 않았다.
