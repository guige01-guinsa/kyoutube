# K-youtube 1.0.1 출시 메모

## 1.0.1+50 출시 후보

- 서식 도구를 Android/iOS의 텍스트 선택 메뉴와 하나로 합쳐 화면과 키보드를 가리지 않도록 개선했습니다.

## 1.0.1+50 확인 항목

- 제목·요약·재료·조리 순서·팁에서 일부 텍스트를 선택하고 선택 메뉴의 `서식`을 눌러 선택 범위에만 서식이 적용되는지 확인합니다.
- 서식 메뉴의 `뒤로`를 누르면 기본 편집 메뉴로 돌아가는지 확인합니다.

## 1.0.1+49 출시 후보

- 입력 항목마다 있던 편집 도구를 하나의 플로팅 `선택 영역 서식` 도구로 통합했습니다.
- 선택한 텍스트에만 글자 크기·굵기·색상이 적용되며 저장 후 상세 화면에서도 같은 범위에 유지됩니다.
- 키보드와 중복되던 복사·잘라내기·붙여넣기·음성 받아쓰기 버튼과 앱의 마이크 권한을 제거했습니다.

## 1.0.1+49 확인 항목

- 제목·요약·재료·조리 순서·팁에서 일부 텍스트를 선택하고 플로팅 서식 도구를 열어 선택 범위에만 서식이 적용되는지 확인합니다.
- 서식을 저장한 뒤 레시피 상세와 재편집 화면에서 같은 범위가 유지되는지 확인합니다.

## 1.0.1+48 출시 후보

- YouTube의 `더보기` 안쪽까지 포함한 전체 설명에서 재료·양념·조리 순서를 추출하고 광고·협찬·상품 소개 문구를 제외합니다.
- 첫 초안이 기준에 못 미치면 AI가 근거를 다시 점검해 한 번 자동 보완합니다.
- 실제 재료 3개 이상과 조리 순서 3단계 이상이면 계량이 일부 없어도 편집 가능한 초안으로 성공 처리합니다.
- 기준 미달 초안은 사용 횟수를 차감하지 않고 검색 제외 레시피에 보관합니다.
- YouTube 자막을 클립보드에서 한 번에 붙여넣어 설명이 부족한 영상도 다시 생성할 수 있습니다.
- 레시피 편집기에 글자 크기·굵기·색상, 복사·잘라내기·붙여넣기, 실행 취소·다시 실행, 음성 받아쓰기를 추가했습니다.
- 관리자가 최근 30일 YouTube 초안 성공률과 자동 보완·자막 사용 횟수를 확인할 수 있습니다.

## 1.0.1+48 확인 항목

- 앱의 마이크 권한을 허용한 후 제목·요약·재료·조리 순서·팁 입력란에서 받아쓰기가 동작하는지 확인합니다.
- 계량 없는 재료 3개와 조리 순서 3단계 초안이 저장 화면으로 이동하고 사용 횟수가 한 번만 차감되는지 확인합니다.
- 재료 또는 조리 순서가 3개 미만인 초안은 차감되지 않고 검색 제외 레시피에 표시되는지 확인합니다.
- 편집 서식을 저장한 뒤 상세 화면을 다시 열어도 유지되는지 확인합니다.

## 1.0.1+42 출시 후보

- 영상 검색부터 AI 초안, 내 레시피 저장, 장보기까지 소개하는 앱 내 튜토리얼을 추가했습니다.
- 계정 관리에서 무료·월간 프리미엄·연간 베이직 등급과 AI 사용량을 확인할 수 있습니다.
- 무료 회원의 AI 초안은 1회/일, 5회/주, 10회/월이며 성공한 초안만 차감됩니다.
- Google Play 구독 복원과 서버 검증 기반의 회원 관리 기능을 추가했습니다.

- 영상 검색에 로그인이 필요한 경우 원인 안내와 로그인 버튼을 바로 표시합니다.
- Google 계정 선택 후 앱 로그인 화면으로 되돌아오던 Android OAuth 설정을 바로잡았습니다.
- 장보기 재료의 구매 단위 분류 변경과 저장 동작을 안정화하고, 네 분류 버튼을 한 줄에 온전히 표시합니다.
- `장보기 완료 내역 보기`를 누르면 화면이 멈추던 탭 이동 오류를 수정했습니다.

- 홈 검색을 영상 레시피 우선의 통합 추천 검색으로 변경했습니다.
- YouTube 결과가 6개 미만이거나 검색에 실패하면 공공 레시피로 자동 보완하며 전체 결과는 최대 10개로 제한합니다.
- 로그인하지 않은 상태에서도 공공 레시피 검색 결과를 계속 확인할 수 있습니다.
- 주방의 `재료 찾기` 결과를 YouTube 영상 레시피 검색으로 연결했습니다.
- 중복 레시피 삭제 후 고립된 화면에 `내 레시피로 이동` 복구 동선을 추가했습니다.

- 장보기 재료 수정에서 구매 단위를 항상 선택된 상태로 표시합니다. 무게·부피·개수·포장 분류를 바꿔도 해당 분류의 기본 단위가 자동 선택됩니다.
- 구매 단위 분류 버튼 네 개를 한 줄로 배치해 작은 화면에서도 빠르게 선택할 수 있습니다.
- 홈 레시피 검색 입력란에 한국 요리 검색과 YouTube 레시피 생성 방법을 안내하는 흐르는 문구를 추가했습니다.
- YouTube 검색 결과에서 제목뿐 아니라 썸네일과 카드 영역 전체를 눌러 원본 영상을 열 수 있습니다.
- Google 로그인 버튼을 다시 제공하며, 시스템 브라우저 인증 후 앱으로 돌아오는 OAuth 콜백을 사용합니다.

## Play Console 등록 전 확인

- 업로드할 AAB의 `versionCode`는 42이어야 합니다.
- 개인정보 처리방침 및 계정 삭제 페이지의 공개 HTTPS URL을 Play Console에 등록합니다.
- 실제 기기에서 Google 로그인, YouTube 영상 열기, 장보기 단위 변경을 확인합니다.

## 내부 테스트용 변경 사항

- YouTube 영상 설명란을 기반으로 AI 레시피 초안을 보강할 수 있습니다.
- 영상 자막 또는 조리 메모를 붙여넣어 재료와 조리 순서의 정확도를 높일 수 있습니다.
- AI가 확인한 정보와 영상에서 추가 확인이 필요한 정보를 구분해 표시합니다.
- Google 로그인 완료 후 앱으로 정상 복귀하도록 Android OAuth 딥링크 처리를 포함합니다.
- 상단 메뉴를 정리하고, 검색 제외 레시피를 `내 레시피` 안에서 확인할 수 있습니다.
- 버튼과 입력 영역을 더 읽기 쉽고 누르기 편하게 개선했습니다.

## 테스터 확인 항목

- YouTube 검색에서 영상을 선택하고 레시피를 만들 수 있는지
- AI 레시피 보강 화면에 자막 또는 조리 메모를 붙여넣을 수 있는지
- 재료와 조리 순서가 `확인됨:` 또는 `영상 확인 필요:` 상태로 표시되는지
- 편집 후 새 내 레시피로 저장할 수 있는지
- Google 계정 선택 후 Gmail이 아닌 앱으로 돌아와 로그인되는지
- 상단 `더보기` 메뉴에서 로그인 또는 계정 관리를 찾기 쉬운지
- `내 레시피`에서 직접 만든 레시피와 검색 제외 레시피 탭을 쉽게 전환할 수 있는지
