# Recipe Scout v75 — 운영 배포 완료

2026-09-19 사용자 승인 범위: DB 0063 운영 적용, 운영 웹 배포, `1.0.1+75` 서명 AAB 생성. 별도 승인된 선행 DB 0047도 함께 반영했다.

## 기능과 사용 경로

- 테스터별 업소 연습 공간에 레시피 5개·식단 3개·구매요청 5개·원가/판매가 3개·판매기록 4개, 총 20개 샘플을 만든다.
- 한국어·영어 샘플과 기존 직원 초대·담당별 권한을 제공한다.
- 관리자는 테스트 기간·참여자를 지정하고 종료하거나 연습 공간을 삭제할 수 있다. 실제 업소 공간은 삭제 대상이 아니다.
- 연습 공간에 추가·수정한 자료도 초기화·삭제 대상임을 안내하며 PDF에는 연습용 표시가 붙는다.
- 관리자: 회원 관리자 → **업소 테스트 관리** → 테스트 열기. **모든 회원**을 선택하면 이메일 인증을 마친 회원이 참여한다.
- 테스터: 업소 공동 업무 → **샘플 20개로 업무 테스트**. 각자 별도의 연습 공간을 생성하고, 직원 초대로 함께 사용할 수 있다.

이번 배포에서 테스트 캠페인을 자동으로 열거나 실제 테스터 자료를 생성하지 않았다. 관리자에게 기간·참여 범위 결정권을 유지한다. 자세한 흐름은 [샘플 테스트 운영 안내](business-test-samples.md)를 참고한다.
