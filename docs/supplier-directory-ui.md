# 공급업체 찾기·등록 안내 보완 — 2026-09-15

상태: 운영 웹 배포 완료. 최종 정적 분석 0건·관련 47개 검사·로컬 DB 계약·공개 웹 9개·업체 경로 로그인 보호 6개 검사 통과.

## 화면 변경

- 검색 조건을 처음부터 펼친다. 기본값은 전체이며 특정 품목·지역·원산지를 임의 지정하지 않는다.
- 항목명을 입력 테두리 위에 별도로 배치해 펼침 제목과 겹치던 문제를 해결했다. 부모 영역 너비에 따라 PC 3열·휴대폰 2열·큰 글씨 1열로 배치하며, 휴대폰 브랜드 입력은 한 행을 사용한다.
- 검색창 위에 **업체·상품 등록** 안내를 표시한다. 업체 선택 모드에서도 숨기지 않는다. 등록된 업체가 있으면 **내 업체·상품 관리**로 바뀐다.
- 구매 요청서의 업체 선택창 위에서 등록 화면을 열고 돌아올 수 있도록 `/supplier-business`를 최상위 경로로 배치했다. PC 작업실 틀을 유지하며, 복귀할 때 검색 입력을 보존하고 공개 목록을 다시 조회한다.

## 공개 범위

사용자가 **로그인한 모든 회원에게 공개**를 선택했다. 무료·유료 회원 모두 공개 업체·활성 상품·상품 사진을 조회할 수 있다. 업체 기본정보와 상품·사진 입력 후 **업체 공개하기**를 완료해야 공개 목록에 나타난다. 등록 중인 초안은 본인만 볼 수 있으며, 공개 후에도 수정은 등록자만 할 수 있다. 개인 거래처 메모와 구매 요청서는 공개되지 않는다.

기존 DB0059 권한이 이 범위를 지원하므로 DB 또는 함수 변경은 필요하지 않다. 등록 안내·공개 상태·공개 확인창에서 이 범위를 한글·영어로 명시했다.
