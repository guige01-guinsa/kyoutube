# 작업일지 - 2026년 7월 29일

## 작업 목표
Google OAuth 로그인 기능을 실제로 작동시키기 위한 환경 설정 파악 및 준비

---

## 오늘 확인한 사항

### 1. 프로젝트 구성 파악
- **플랫폼**: Flutter (Android / iOS)
- **인증**: Supabase Auth (Google OAuth 포함)
- **알림**: Firebase Cloud Messaging (FCM)
- **AI**: OpenAI API
- **레시피 API**: 식품안전처 공공 API

### 2. 이미 구현된 코드
| 파일 | 내용 |
|------|------|
| `lib/features/auth/presentation/login_page.dart` | Google OAuth 로그인 버튼 및 `signInWithOAuth` 구현 완료 |
| `lib/features/auth/application/auth_providers.dart` | Supabase 인증 상태 스트림 구현 완료 |
| `android/app/src/main/AndroidManifest.xml` | `io.supabase.kyoutube://login-callback` 딥링크 intent-filter 설정 완료 |
| `lib/core/config/env.dart` | 환경별(local/staging/production) Supabase URL·Key 분기 및 검증 로직 완료 |

### 3. Google OAuth 설정 흐름 정리
```
Google Cloud Console에서 OAuth 클라이언트 생성
    ↓
Client ID / Client Secret 발급
    ↓
Supabase 대시보드 → Authentication → Providers → Google에 입력
    ↓
Flutter 앱에서 signInWithOAuth(OAuthProvider.google) 호출
    ↓
브라우저 → Google 로그인 → Supabase callback → 앱으로 복귀
```

## 남은 작업 (미완료)

### 🔴 1순위 - 앱 실행을 위해 즉시 필요
- [ ] `.env` 파일 생성 (`.env.example` 복사 후 실제 값 입력)
  - `SUPABASE_URL_LOCAL` / `SUPABASE_ANON_KEY_LOCAL`
  - `SUPABASE_URL_PRODUCTION` / `SUPABASE_ANON_KEY_PRODUCTION`

### 🟠 2순위 - Firebase 기능을 위해 필요
- [ ] `android/app/google-services.json` 다운로드 및 배치
  - Firebase Console → 프로젝트 설정 → Android 앱 → 파일 다운로드
- [ ] `ios/Runner/GoogleService-Info.plist` 다운로드 및 배치
  - Firebase Console → 프로젝트 설정 → iOS 앱 → 파일 다운로드

### 🟡 3순위 - Google OAuth 실제 연동
- [ ] Google Cloud Console에서 OAuth 클라이언트 ID 생성
  - Application type: Web application
  - Authorized redirect URI: `https://<supabase-ref>.supabase.co/auth/v1/callback`
- [ ] Supabase 대시보드 → Authentication → Providers → Google에 입력
  - Client ID 입력
  - Client Secret 입력

### ⚪ 4순위 - 배포 시 필요
- [ ] `android/key.properties` 생성 (Play Store 릴리즈 서명용)

## 메모
- `APP_ENV=local` 상태에서는 로컬 Supabase(`http://127.0.0.1:54321`)에 연결됨
- 로컬 Supabase의 anon key는 `supabase start` 명령 실행 후 출력값에서 확인 가능
- Google OAuth는 Supabase가 중간 브릿지 역할을 하므로, Flutter 앱에는 별도 Google SDK 불필요
