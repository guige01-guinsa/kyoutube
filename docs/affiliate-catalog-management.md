# 식자재 제휴 상품 관리

관리자 홈의 새 **상품 등록·공개 도우미** 메뉴는 [등록 절차 안내](affiliate-registration-workflow.md)를 참고하세요.

> 2026-09-26: 관리자용 쿠팡 API 상품 검색·링크 생성 개발은 [쿠팡 파트너스 API 연동](coupang-partners-api.md)을 참고하세요. 이 추가 기능의 운영 적용은 별도입니다.

작성: 2026-09-24. 개발 구현 및 로컬 검증 대상. 운영 DB·웹에는 아직 반영하지 않았고 새 AAB는 만들지 않았습니다.

## 관리자 사용 순서

1. 관리자 로그인 → 2단계 인증 → 회원 관리자 → **제휴 상품 관리**.
2. 한 개를 추가하려면 **제휴 상품 추가**. 제휴사, 상품명, 분류, 브랜드, 관리 번호, 규격, 재료 별칭, 발급 링크를 입력하고 초안으로 저장합니다. 관리 번호와 분류·브랜드는 선택 항목입니다.
3. 여러 개는 **목록 가져오기** → 붙여넣기 또는 파일 선택 → **중복 확인·미리보기**. 체크한 항목만 저장합니다. 신규 항목은 기본 선택되고 기존 상품·휴지통 상품·입력 오류는 선택되지 않습니다.
4. 기존 상품을 선택하면 해당 상품을 수정하고 초안으로 돌립니다. 수정 전 상품명도 표시합니다. 휴지통 상품은 먼저 복원해야 합니다. 현재 공개 중인 상품을 일괄 수정하면 공개가 중단됩니다.
5. 저장 결과를 행별로 확인합니다. 실패·수정 충돌은 원본을 수정한 후 다시 미리보기 합니다. 통신 응답을 받지 못했을 때는 재조회하여 실제 저장 여부를 확인합니다. 같은 발급 링크가 두 번 생성되지 않도록 서버에서도 검사합니다.
6. **수정 → 실제 상품 확인**으로 연결된 상품·규격을 대조합니다. 상품별 규격, 확인 체크, 게시 위치, 사용 허용 근거·확인일을 기록한 뒤 공개합니다. 쿠팡 상품은 실제 상품 확인과 규격이 필수입니다. 제휴사 승인을 자동으로 대신하는 체크가 아닙니다.
7. 목록의 검색·상태 필터를 이용합니다. 전체/초안/공개/만료/휴지통과 25개씩 페이지 이동을 지원합니다. 현재 페이지에서 여러 상품을 선택해 공개·공개 중단·휴지통 이동·복원을 할 수 있습니다.
8. 삭제는 휴지통 이동입니다. 복원하면 초안 상태가 됩니다. 상품의 **변경 이력**에서 변경 전후 값, 처리 계정, 시각을 확인할 수 있습니다. 기존 레시피와 구매 기록은 삭제하지 않습니다.

## 사용자 구매 흐름

장보기 도우미 → 재료의 구매처 찾기 → 재료에 맞는 제휴 상품 → 규격과 수수료 안내 확인 → **쿠팡에서 구매**.

발급받은 링크를 원문 그대로 외부에서 엽니다. 앱 안에서 결제하거나 구매 완료·재고 차감·수익 확정을 자동 처리하지 않습니다. 최종 가격·배송비·재고는 판매처에서 확인합니다. 일반 검색과 네이버/YouTube 연결도 유지됩니다.

공개·유효기간·현재 이용 위치(앱/웹)를 만족하는 상품만 보입니다. 재료 별칭은 앞뒤 공백과 대소문자를 정규화하여 정확하게 일치시킵니다. 예: `달걀, 계란`. 임의의 부분 일치로 다른 부위나 규격을 추천하지 않습니다. 한 재료에 여러 상품을 등록할 수 있고 현재 사용자 화면에는 이름순 최대 6개를 표시합니다.

## 가져오기 형식

- UTF-8 TXT/CSV/TSV 및 XLSX. 파일은 최대 2MB, 한 번에 최대 2,000개 데이터 행입니다. 전체 DB 등록 수를 100개로 제한하지 않습니다.
- XLSX는 첫 번째 시트만 사용하며 수식 셀이 있는 행은 오류로 표시합니다. 압축 메타데이터 합계 20MB 및 2,000개 데이터 행 제한을 두며 심볼릭 링크를 받지 않습니다. 암호화 파일과 구형 XLS는 지원하지 않습니다.
- CSV/TSV 첫 행은 열 이름입니다. 필수: `title,link`. 선택: `source_code,category,specification,brand,ingredients,program`.
- 한글 열 이름: 상품명, 제휴 링크, 관리번호, 분류, 규격, 브랜드, 재료, 제휴사. 재료 별칭은 쉼표·세미콜론·파이프 구분이며 CSV에서는 쉼표가 든 필드를 큰따옴표로 감쌉니다.
- `ingredients` 열을 생략하거나 재료 셀을 비우면 상품명을 재료 이름으로 사용합니다. 브랜드가 붙은 상품명은 재료 별칭을 별도로 입력하는 것이 좋습니다. 상품명까지 없는 행은 입력 오류로 표시하고 다른 행의 가져오기는 계속합니다.
- 제목 행을 포함해 복사한 7열 엑셀 표(TSV) 또는 CSV는 **빠른 붙여넣기 미리보기**와 **중복 확인·미리보기** 양쪽에서 읽습니다. CSV 인코딩 오류는 UTF-8 저장 또는 XLSX/표 복사 방법을 안내하며, 관리자 권한·2단계 인증·서버 중복 확인 실패는 파일 오류와 구분합니다.
- `001 진간장 https://link.coupang.com/a/...` 형식과 사용자가 전달한 탭 구분 원문도 지원합니다.
- CSV를 만들기 어려우면 `재료명 | 상품명 | 제휴 링크`를 한 줄씩 붙여넣습니다. `상품명 | 제휴 링크`만으로도 등록할 수 있으며, 분류·규격·브랜드·관리 번호는 나중에 보완합니다.
- 빠른 붙여넣기에서 분류까지 지정하려면 `분류 경로 | 재료명 | 상품명 | 제휴 링크`, 관리 번호까지 지정하려면 `관리번호 | 분류 경로 | 재료명 | 상품명 | 제휴 링크`를 사용합니다. 이전 `관리번호 | 재료명 | 상품명 | 제휴 링크` 형식도 그대로 지원합니다.
- 분류를 비우면 재료 별칭을 기준으로 아래 식품 분류 경로를 자동으로 제안합니다. 자동 제안이 맞지 않으면 미리보기에서 확인한 뒤 수정합니다.

## 식자재 분류 경로

제휴상품 관리는 쿠팡 식품 탐색 구조처럼 **대분류 > 구매 그룹**을 사용합니다. 현재 지원 경로는 신선식품(채소·과일·버섯/나물), 축산·수산(소·돼지·양, 닭·오리, 생선·해산물), 유제품·달걀, 콩·두부·견과, 쌀·잡곡·면·가루, 장류·소스·오일, 가루·조미료, 김치·반찬·간편식, 통조림·건식, 베이커리·잼·디저트, 음료·차·커피, 건강·특수식, 기타·분류 확인입니다.

장보기 화면은 같은 분류 체계를 읽기 쉬운 대분류로 표시합니다. 기존에 저장된 `곡류·가공식품` 분류는 유지되며, 새 항목부터는 더 구체적인 분류를 사용합니다.
- 같은 링크는 한 상품만 등록합니다. 상품의 관리 번호는 순번용 보조 정보이며 DB 식별자는 별도의 UUID입니다.
- 가져온 자료는 기존 상품 수정 여부와 무관하게 초안·미검증 상태입니다. 등록된 가격을 자동 갱신하거나 쿠팡 API를 호출하지 않습니다.

## 최초 100개 자료

`tools/data/affiliate-catalog/initial-100-drafts.csv`를 선택해 가져올 수 있습니다. 원문은 같은 폴더의 `initial-100-source.txt`에 보존했습니다.

100개 번호와 100개 고유한 발급 링크를 확인했습니다. 원문에 분류가 없던 001~003은 기본 양념·기름으로 정리했습니다. 원문의 ★ 표시는 CSV의 source_note에 보관했으며 공개 승인·우선순위로 해석하지 않았습니다. source_note는 참고 열로 DB 가져오기에서 제외됩니다. 실제 목적지·판매 상품·규격 확인은 아직 하지 않았으므로 자동 공개하지 않습니다.

## 구현 및 배포 메모

- 신규 마이그레이션 `0071_affiliate_catalog_management.sql`. 기존 0065와 0060의 관리자 MFA 검사에 의존합니다. 기존 마이그레이션은 수정하지 않습니다.
- 관리자 RPC만 변경 가능. 직접 테이블/이력 접근은 차단합니다. 일반 회원은 승인 메모·관리자 ID·휴지통 자료를 조회하지 못합니다.
- 등록·수정은 revision 충돌 검사와 목적지별 트랜잭션 잠금으로 중복을 막습니다. 화면은 최대 2,000개를 받지만 서버에는 최대 100개씩 자동 전송하고 행별 결과를 반환합니다. 수정 action은 기존 revision이 있어야 합니다.
- 공개는 만료·사용 위치·검토 메모와 쿠팡 상품 확인 조건을 서버에서 다시 검사합니다. 링크/제휴사를 바꾸면 이전 승인은 해제되고 초안으로 저장됩니다. 다시 열어 검토 후 공개합니다.
- 유효기간은 편집 저장 시 30일입니다. 만료 상품은 사용자에게 표시하지 않습니다. 실제 판매 중단/링크 깨짐 자동 감시 기능은 포함하지 않습니다.
- 휴지통 자료는 영구 삭제하지 않습니다. 감사 이력은 append-only RPC 경로로 기록되고 관리자 계정 삭제에도 호환됩니다.
- 구버전 관리자 목록 RPC에는 기존 네이버/YouTube 상품만 반환하여 구버전 편집기의 미지원 제휴사 오류를 방지합니다. 새 쿠팡 관리는 업데이트된 관리자 화면에서 사용합니다.
- 앱/웹 세션 변경 시 대화상자·선택·진행 중 후속 작업을 중단합니다. 원래 계정에서 이미 완료된 요청은 되돌리지 않으므로 새로고침으로 확인합니다.
- 2026-09-24 사용자 승인으로 DB migration 0071만 선택 적용하고 웹 v81 및 새 AAB를 배포했습니다. 관리자 초안 등록 → 실제 상품 검토 → 공개는 아직 수행하지 않았습니다.
- 새 유료 API는 추가하지 않습니다. 기존 DB 읽기/쓰기·저장공간 사용량은 상품 및 이력 수에 따라 증가합니다.
