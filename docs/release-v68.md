## 사용 방법

장보기 → 구매 요청서 → **구매요청 대장 · 검색·집계·출력**에서 기간·업체·상태·사업자번호 검색, 통화별 입력 단가 집계, 변경 이력, 요청서 열기·수정·반복 요청, CSV/PDF 출력을 이용한다. 입력 단가가 없는 품목은 견적 대기로, 취소 요청은 합계에서 제외한다.

요청 업소와 공급업체 양쪽 사업자등록번호 및 등록증 사진을 저장하고 번호를 눌러 사진을 확인한다. PDF 미리보기·저장·인쇄는 기존 Plus/Business 권한을 따른다. 사본 첨부는 기본 해제이며 사용자가 선택한 사진만 포함한다. 공유나 인쇄는 발송/입고 상태를 자동 변경하지 않는다. 취소하면 대장 기록을 보존하고 삭제하면 해당 요청의 이력도 삭제된다.
