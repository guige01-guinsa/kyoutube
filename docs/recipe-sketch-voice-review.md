# 레시피 스케치·캐릭터 음성 검토

레시피 전용 프로필은 기존에 글자 카드만 표시했다. 이제 원문의 재료와 조리 문구에 맞춰 서버에서 직접 그리는 색연필 형태의 개념 스케치를 모든 장면에 표시한다. 외부 이미지 다운로드와 유료 이미지 생성 요청은 없다. 수량·단위·조리 순서는 기존 원문을 그대로 표시한다. 그림은 정확한 분량을 나타내는 계량 자료가 아니며 화면 하단에 `조리 개념 스케치`를 표시한다.

완성 영상의 각 장면 중간 프레임을 디코딩해 그림 영역이 비어 있거나 검은 화면인지 확인한다. 확인한 장면 수와 그림 대비 정보가 누락되면 미리보기 저장을 중지한다. 기존 길이·프레임 수·음성·파일 해시 검사도 유지한다. 실제 음성이 3분 이상이면 게시 전 계속할지 사용자의 결정을 받는 기존 운영 기준은 유지한다.

레시피 프로필의 새 음성은 `fictional-girl-8-ko-v1`이다. 기존 허용 모델 `gpt-4o-mini-tts`와 `shimmer` 기본 음성에 가상의 8세 소녀 캐릭터, 밝고 가벼운 높은 음역, 자연스러운 한국어 억양과 정확한 계량 발음을 지시한다. 실제 어린이를 모사하지 않는다. 특정 연령처럼 들리는 정도는 모델 결과에 따라 달라지므로 음성 견본을 확인해야 한다. AI 음성 표시는 계속 제공한다. 구형 백과사전 재편집과 1분 이야기 프로필의 기본 `coral` 설정은 보존한다.

음성 프로필을 캐시 키와 레시피 검토 해시에 포함한다. 이전 성인 음성을 새 캐릭터 음성으로 오인해 재사용하지 않는다. 새 목소리를 선택하면 새 음성 생성 비용이 필요하지만 실패 후에는 같은 설정으로 저장된 문단을 이어 사용할 수 있다. 재시도는 여전히 별도 승인 작업이며 무제한 자동 재시도하지 않는다.

운영 반영 전 검토 항목: 기존 레시피와의 문자 단위 대조, 모든 그림 장면의 인코딩 후 검사, 새 캐릭터 음성의 전달·캐시 분리 검사, 원문 누락·긴 음성·그림 없는 영상의 중단 검사. DB 구성과 웹 화면 변경은 필요하지 않다. 운영 반영 및 유료 음성 제작은 승인을 받은 범위에서만 진행한다. 기존 업로드 영상과 비공개 자료를 덮어쓰지 않는다.
