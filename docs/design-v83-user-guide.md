# v83 화면 확인 안내

## 웹에서 보기

https://recipe-scout-workspace.web.app/ 를 열고 새로고침한다. 기존 탭에 이전 화면이 남으면 `Ctrl+F5`로 다시 불러온다.

## 가장 쉽게 변화 확인하기

1. **일반 사용자 → 레시피 수집**: 검색과 수집 행동, 저장 위치를 확인한다.
2. **업소·전문가 → 작업공간**: 업소별 카드와 개인 작업실 구분을 확인한다.
3. **사용자명 레시피 → 새 레시피**: 기본 정보·재료·조리 순서·선택 자료별 입력 그룹을 확인한다.
4. **레시피 상세**: PC는 재료와 조리 순서를 두 열로, 모바일은 한 열로 보여준다.
5. **업소 → 메뉴판 관리 → 판매 메뉴로 빠른 구매**: 단계 안내와 수량 입력 배치를 확인한다.
6. **관리자 홈**: 회원·제휴 상품 등 관리 업무를 이름이 있는 카드로 선택한다. 일반 계정에는 노출되지 않는다.
7. **내 계정**: 이용 설정·보안·도움말과 로그아웃·탈퇴 영역의 구분을 확인한다.

기존 레시피·업소·권한·구매 자료를 계속 사용한다. 이 디자인 릴리스는 제휴 상품을 자동 공개하지 않는다.

## Android

새 AAB는 Google Play 배포용 파일이다. 휴대폰에서 직접 여는 설치 파일이 아니다. Play Console의 해당 트랙에 업로드하고 출시한 후 휴대폰에서 업데이트해야 새 화면이 반영된다.

`.artifacts/design-complete/index.html`은 실제 앱 위젯과 예시 자료로 만든 미리보기 모음이다. 실제 운영 회원 데이터가 아니다. 최종 릴리스 결과와 알려진 한계는 `docs/release-v83.md`에서 확인한다.
