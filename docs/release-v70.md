# Recipe Scout v70 — 2026-09-17

사용자 승인으로 메뉴와 구매 흐름 개편을 **운영 웹과 1.0.1+70 서명 AAB**에 반영했다. DB·서버 함수 변경은 없으며 기존 v69 업로드 서명을 유지했다. Play 업로드와 휴대폰 설치는 수행하지 않았다.

## 변경 사항

| 이용 목적 | 주요 메뉴 |
|---|---|
| 일반 사용자 | 검색 / 내 레시피 / 장보기 / 내 정보 |
| 업소·전문가 | 홈 / 구매 / 거래처 / 셰프 / 내 정보 |
| 식자재 공급업체 | 홈 / 업체·상품 / 내 정보 |

구매 화면에서 준비 중·진행 중·완료 요청을 모아 보고, 재료 선택 → 업체·기준 선택 → 초안 검토 → 저장·공유로 진행한다. 이전 요청 재사용, 요청서 직접 열기, 단계 이동 후 선택 유지, 같은 앱 실행 중 이어쓰기를 지원한다. 계정·설정·튜토리얼은 내 정보에 모았다. 셰프 작업실과 장보기에서 구매 준비로 연결한다.

임시 이어쓰기는 앱 종료·웹 새로고침 후 보존되지 않으므로 완성한 요청은 저장해야 한다. 조리량과 구매량은 구별하며 구매 수량은 사용자가 확인한다. 공급자 수락·입고 상태는 구매자가 확인해 기록하는 기존 기능이다. [세부 변경·사용 방법](purchase-navigation.md).
