# 사무실 개발 소스 검증 기록

2026-10-10에 GitHub 최신 릴리스 브랜치의 홍보 기능과 집 PC의 v99 기능 소스·이미지·폰트·웹·신규 DB 마이그레이션을 합친 복제본을 검사했습니다. 운영 DB·함수·앱·웹은 이 소스 업로드 작업에서 변경하지 않았습니다.

- Flutter SDK: `.fvmrc`의 3.44.8, 프로젝트 FVM 경로 사용. 의존성 설치 성공.
- 처음 수행한 전체 정적 분석: 문제 없음.
- 처음 수행한 전체 Flutter 테스트: 854개 통과, 4개 건너뜀, 5개 실패. 홍보 번역 누락 2개와 공개 테스트 자료 누락 1개를 통합 범위 내에서 보완하고 관련 검사를 재실행했습니다.
- 홍보 worker 단위 테스트: 8개 통과.
- 홍보 Edge Function 타입 검사: 통과.
- 소스 파일에 대한 비밀 키 패턴 검사: 발견 없음. 환경 파일·서명 키·로컬 Firebase 설정·빌드·배포 산출물·로그·마케팅 이미지 제작 산출물은 포함하지 않습니다.

남은 기존 실패:

1. `test/features/shopping/ingredient_photo_test.dart`: ‘감자전분’은 사진 별칭을 매칭하지 않아야 한다는 기대와 현재 결과가 다릅니다. 집 PC 기존 소스에서도 같은 실패를 재현했습니다.
2. `test/widget_test.dart`의 `home screen renders`: 홈 데이터가 이미 변경됐지만 검사는 예전 ‘한국어 영상 · 하루한끼’ 문구를 기대합니다. 제품 기능을 이전 데이터로 되돌리지 않습니다.

이 두 검사는 별도 작업으로 검토해야 하며, 현재 개발 브랜치의 전체 품질 검사가 전부 통과했다고 볼 수는 없습니다.

`flutter doctor`는 이 PC의 SDK PATH, Android 라이선스 및 Windows용 Visual Studio 설치 경고를 보고했습니다. 프로젝트 Flutter 3.44.8과 JDK 17은 사용 가능했으며 사무실 PC에서는 본인 환경에서 bootstrap/verify를 수행해야 합니다.

최종 확인: 전체 정적 분석은 문제 없음을 확인했고 홍보 통합·번역·공개 자료 집중 검사 19개가 모두 통과했습니다. 위 두 기존 실패는 집 PC 원본에서도 각각 재현했습니다.
