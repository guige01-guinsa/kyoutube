# 구매 전 장보기 목록 정리

장보기 도우미 → **장보기 목록 정리** (`/shopping-preparation`)에서 사용합니다.

1. 합칠 활성 장보기 목록을 선택합니다. 같은 이름·호환되는 단위의 미구매 재료만 합칩니다.
2. 채소·과일, 육류·수산물, 유제품·달걀, 양념·오일, 곡류·가공식품, 기타로 정리합니다. 분류는 수정 가능합니다.
3. 수량이 확인된 재료에 실제 사용할 보유량을 입력합니다. 기록된 재고는 참고로만 표시하며 자동 차감하지 않습니다. 필요량은 보존하고 구매 예정량을 별도로 수정합니다.
4. 수량이 불명확한 재료는 원래 장보기 목록에서 수량·단위를 보완하거나 이번 구매에서 제외합니다. 수량 미확인 항목이 포함된 상태에서는 확정하지 않습니다.
5. 구매 리스트를 확정한 뒤 구매처 찾기·분류별 복사·실제 구매 기록을 이용합니다. 확정만으로 주문, 재고 차감, 구매 완료 처리는 하지 않습니다.

## AI 분류 추천

- 기본 분류 후 `AI 분류·같은 재료 찾기`로 분류와 동일 식재료 후보를 요청합니다. 20개를 넘으면 확인 범위를 선택합니다. 동일 재료 비교는 선택한 범위 안에서 이루어집니다.
- 버튼을 누르면 한 번에 최대 20개의 재료 이름과 임시 번호만 보냅니다. 재고, 레시피 내용, 수량은 전송하지 않습니다.
- 기존 `ai_purchase_request_review` 함수에 `task: categorize`를 추가했습니다. 기존 로그인 검증과 회원 AI 사용량 예약·정산을 그대로 사용합니다.
- AI 응답은 요청한 번호와 허용된 6개 분류, 기존 번호만 참조하는 동일 재료 후보 묶음을 허용합니다. 누락·중복 번호, 추가 수량, 임의 분류를 거부합니다. 같은 분류라는 이유만으로 합치지 않습니다. 동일 재료 추천은 별도의 확인 버튼을 눌러야 적용됩니다.
- 사용자가 동일 재료임을 확인하면 kg/g, L/ml 및 같은 개수 단위를 합칩니다. 원래 재료명과 출처는 보존합니다. 합친 뒤 보유량·구매 예정량은 재확인하며, 합치기 취소로 되돌릴 수 있습니다.
- 이름이 다른 재료를 합친 결과는 구매 준비용입니다. 기존 구매 기록 서버의 원래 이름 검증을 유지하므로 실제 구매 기록은 원래 재료별 화면으로 연결합니다.
- AI 요청이 실패하거나 한도를 초과하면 수동 분류를 계속 사용할 수 있습니다.
- 2026-09-27 사용자 승인으로 운영 AI 함수를 배포했습니다. 실제 호출 1회로 분류·동일 재료 추천과 사용량 기록을 확인했으며 테스트 계정과 자료를 정리했습니다.

## 보존과 제한

- 정리 결과는 기기/브라우저의 로컬 저장소에 계정별로 저장됩니다. 웹·앱 간 자동 동기화는 하지 않습니다.
- 원래 목록 또는 재고 내용, 날짜가 달라지면 보유량·확정을 다시 확인합니다. 선택 목록을 바꾸면 기존 수정값을 초기화하여 중복 재고 차감을 방지합니다.
- 자동 합산은 이름이 정확히 일치할 때만 합니다. 이름이 다른 경우에는 AI 후보에 대한 사용자 확인이 필요합니다. g/kg, ml/L와 같은 분명한 단위만 환산하며, 한 줌·조리용 숟가락·포장 크기를 추정하지 않습니다. 포장 단위는 자동 합산하지 않습니다.
- 기존 v87/v88 출시 파일에는 이번 변경이 포함되지 않습니다. 새 v89 출시·배포 상태는 [v89 기록](release-v89.md)을 확인합니다.
