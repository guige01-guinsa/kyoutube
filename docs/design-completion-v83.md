# 디자인 전체 흐름 정리 — v83

2026-09-25. 기존 1차 개편에 남아 있던 세부 입력·관리 화면을 정리한 후속 작업이다. 아래는 구현 범위이며 최종 배포·검증 결과는 release-v83.md에 기록한다.

## 공통 기준

- 따뜻한 배경과 흰 작업 패널을 구분하고 녹색은 주요 행동·선택에 사용한다.
- 제목/설명/작업 영역/입력 그룹의 순서를 통일한다. 공통 컴포넌트는 `lib/core/widgets/scout_page.dart`다.
- 화면 목적별 최대 너비를 사용한다: 인증 640, 일반 입력 880–900, 목록·업무 1000–1200. 기존 원가 작업대처럼 비교 열이 필요한 화면은 별도 너비를 유지한다.
- 고정 높이 격자 대신 콘텐츠 높이에 맞는 카드 배치를 사용한다. 좁은 화면이나 큰 글씨에서는 한 열로 바뀐다.
- 키보드 입력, 기존 스크롤, URL, 데이터 조회·저장, 편집 종료 보호는 기존 화면이 계속 담당한다.

## 화면별 마무리

| 영역 | 반영 내용 |
|---|---|
| 일반 홈 | 수집 목적과 저장 위치를 구분하고 검색·영상·보유 재료·저장 레시피를 먼저 제공 |
| 업소 선택 | 긴 가로 목록을 업소별 카드로 교체, 공동 업무와 개인 연구 공간 분리 |
| 개인 작업실·더보기 | 담당 업무 제목 체계와 도구 카드 통일 |
| 내 레시피 | 이름 있는 새 레시피 버튼, 실제 목록 개수, PC 검색/정렬 2열·모바일 1열 |
| 레시피 작성 | 소개/재료·분량/조리/선택 자료 4개 입력 그룹, 필수·선택 안내 |
| 레시피 상세 | PC 재료/조리 2열, 모바일·큰 글씨 1열, 과도한 사진 높이 제한 |
| 재료·추천 검색·AI 초안 검토 | 읽기/입력 폭 제한과 공통 제목, 기존 검색 및 검토 동작 보존 |
| 메뉴 관리·빠른 구매 | 후보→출시→판매 안내, 실제 선택·계산 단계, 반응형 수량 입력 |
| 업소 문서 작성 | 레시피·식단·원가·판매·구매에 맞는 입력 그룹 |
| 입고·재고 | 현재고/예약량/사용 가능량을 별도 표시, 입고·반품 동작 유지 |
| 거래처·직원 | 연락정보·포장규격·사용상태 그룹, 권한 안내와 구성원 구분 |
| 구매 요청·대장 | 검색 패널, 요청 단계, 문서 미리보기 너비 제한 |
| 계정·인증·구독 | 설정·보안·도움말 카드, 로그아웃·탈퇴 하단 분리, 읽기폭 제한 |
| 관리자 홈 | 작은 아이콘 모음 대신 6개 업무별 텍스트 카드, 회원 검색·목록 |
| 제휴 상품 | 등록→검색·검토→선택 작업 구분, 편집 3그룹, 공개 상태 표시 |
| 공급업체·운영 | 업체/상품/거래조건별 제목, 운영 현황과 알림함 구분 |

이전 1차에서 정리한 로그인·튜토리얼·공급업체 검색·장보기의 기존 구성은 유지하고 공통 테마와 함께 사용한다. 권한 및 서버 설정을 바꾸는 디자인 작업은 아니다. 관리자 홈은 추가로 로그인과 관리자 권한 확인이 끝나기 전에 관리 카드나 회원 조회를 노출하지 않도록 보완했다.

## 검증 원칙과 결과 위치

- 새 회귀 검사: 한영 320px·200% 글씨, 390px 모바일, PC, 긴 업소명, 구매 인분 보존, 확인 전 초안 생성 차단, 관리자/일반/로그아웃/권한 확인 중 상태.
- 기존 저장·실행 취소·편집 종료 보호 및 전체 테스트도 실행한다.
- `.artifacts/design-complete/`의 캡처는 실제 Flutter 위젯을 가상 자료로 렌더링한 것이다. 운영 회원 자료나 운영 로그인 화면의 캡처로 해석하지 않는다.
- 운영 배포 후 읽기 전용 웹 검사와 별도로 Android 최종 ZIP의 글꼴 등록·파일·서명을 확인한다.
- Play Console 업로드 및 Play를 통한 실제 휴대폰 업데이트는 이 릴리스 생성 작업과 구분한다.
