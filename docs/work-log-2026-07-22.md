## Technical insights & lessons

### OAuth 환경 변수 설정
**Lesson:** Docker 컨테이너에서 `env()` 참조는 **호스트 환경 변수**를 찾으려고 시도합니다. 
- ✅ **해결책:** TOML 파일에 직접 값 입력 또는 Docker run 시 `-e` 플래그로 전달
- ⚠️ **피할 것:** `.env` 파일의 값을 `env()` 참조로 간접 참조

### Supabase로컬 개발 최적화
**Best practice:**
1. 변경사항이 있을 때마다 `supabase stop; supabase start` (전체 재시작)
2. 특정 서비스만 재시작하면 설정이 반영되지 않을 수 있음
3. 환경 변수는 시작 시에만 로드되므로, 값 변경 후 재시작 필수

### Flutter OAuth 위젯 생명주기
**Lesson:** `initState`에서 auth 리스너를 추가할 때, 위젯 disposal 후 접근 에러 발생 가능.
- ✅ **해결책:** `WidgetsBinding.addPostFrameCallback` 사용 + `mounted` 체크
- 이미 [LoginPage](lib/features/auth/presentation/login_page.dart)에서 구현됨
