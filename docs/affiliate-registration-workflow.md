# 상품 등록·공개 도우미

관리자 홈 → 상품 등록·공개 도우미에서 초안 상품부터 검토합니다.

1. 제휴 상품 추가, 목록 가져오기 또는 쿠팡 상품 검색·링크 생성으로 등록합니다. API 기능은 별도 서버 설정과 키가 필요하며, 직접 발급 링크 등록에는 API 키가 필요하지 않습니다.
2. 각 상품의 미완료 항목을 읽고 수정에서 실제 링크를 열어 상품명·규격을 확인합니다.
3. 게시 가능한 위치와 근거를 직접 확인한 뒤 공개 여부를 선택하고 저장합니다. 도우미는 확인·공개 체크를 자동으로 하지 않습니다.
4. 상품의 실제 노출 확인을 누르면 재료 이름을 미리 채워 회원용 조회를 실행합니다. 현재 기기에 허용되고 공개 중이며 유효한 상품만 표시됩니다. 검색어를 바꿔 다시 조회할 수 있습니다.
5. 미노출 시 공개 여부·게시 위치·만료일·재료 별칭을 점검합니다. 이 화면은 쿠팡 최종 승인 여부를 판정하지 않습니다.

기존 상태 필터, 일괄 작업과 변경 이력을 유지합니다. 새로운 서버 기능이나 데이터베이스 변경은 없습니다. 관리자 로그인 및 기존 2단계 인증 경로를 사용합니다. 실제 휴대폰에서 메뉴를 사용하려면 앱 업데이트가 필요합니다.
