# 영어 YouTube·초안·조리 정확도 재검증

기준: 2026-09-12, v54 소스 및 기존 운영 통계. **현재 자료만으로 영어 전체 흐름의 성공률이나 조리 정확도가 90% 이상이라고 판정할 수 없다.**

후속 수정: 사용자 실기기 실패/성공 화면을 검토하고 검색 언어·제목 정규화·간단한 요리·보정 조건을 개선했다. [영어 초안 안정성 개선 기록](english-reliability-fixes-2026-09-12.md)을 참조한다. 아래 표와 모의 수용 시험은 수정 전 v54 기준 진단이며, 운영 배포 및 새 AAB 반영은 아직 수행하지 않았다.

## 확인된 문제

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 영어 검색 연결 | 누락 발견 | `YoutubeSearchPage`와 `recommendedRecipeSearchServiceProvider`가 localeProfileProvider 없이 transport 생성. 기본값 ko/KR |
| 영어 초안 요청 | 연결 있음 | 편집 페이지에서 en-US 전달, 서버 영어 프롬프트 및 영어 결과 테스트 존재 |
| 검색 결과 언어 | 영어만 보장하지 않음 | relevanceLanguage는 우선순위이며 다른 언어의 관련 결과도 반환 가능 |
| 실제 영상 이해 | 설명/입력 자막에 한정 | 프레임·오디오 분석 없음. captionAvailable은 자막 본문이 아님 |
| 품질 성공 기준 | 조리 정확도 검증에 부족 | 현재 기준은 주로 재료 3개·단계 3개. 원문 계량·온도·시간 대조, 영어 출력·중복 검증 없음 |
| 영어별 운영 지표 | 없음 | 기존 사용 원장·품질 지표에 outputLocale 컬럼 없음 |

영어 검색 단위 테스트는 영어 프로필을 직접 주입하므로 실제 화면의 연결 누락을 잡지 못한다. 실제 앱 기본값과 주입된 테스트 설정을 구분해야 한다.

Google 공식 문서: [search.list](https://developers.google.com/youtube/v3/docs/search/list)는 다른 언어 결과도 반환할 수 있다고 설명한다. [captions.list](https://developers.google.com/youtube/v3/docs/captions/list)는 자막 본문을 반환하지 않으며, [captions.download](https://developers.google.com/youtube/v3/docs/captions/download)는 적절한 권한을 요구한다. 모든 영상 자막을 일반 API 키로 자동 취득한다고 가정하지 않는다.

## 기존 서버 집계 — 영어 성공률로 사용 불가

읽기 전용으로 최근 30일을 조회했다. 개별 사용자·레시피·인증 정보는 가져오지 않았다.

- YouTube AI 사용 원장: 48건, 성공 21건·실패 27건·미완료 0건. 43.75%이며 과거 버전·언어가 섞인 누적 기록이다.
- 별도 품질 지표: 11건 중 성공 10건·실패 1건(90.91%), 설명 있음 11건·입력 자막 있음 0건·보완 시도 2건.
- 두 표의 수집 범위가 다르므로 같은 모집단으로 합치거나 비교 증감률을 계산하지 않는다. 후자의 90.91%도 영어·조리 정확도 검증 결과가 아니다.
- 10/11의 Wilson 95% 신뢰구간 하한은 약 62.26%다. 작은 표본의 관측 비율만으로 90% 이상을 주장할 수 없다.

## 모의 수용 판정 시험

`tools/test/english_quality_probe.ts`는 실제 모델을 호출하지 않고 의도적으로 구성한 응답을 주입했다. **실제 AI 오류 발생률을 측정한 시험이 아니다.**

원문에 소금 2g·200°C·20분이 있는데 200g 또는 350°C·2분을 반환해도 서버는 200 성공으로 처리했다. 중복 재료/단계, 한국어 응답, 근거 없는 ingredientNames, 빈 요약, 근거 없는 수치가 있는 초안도 수용했다. 빈 요약은 서버가 성공으로 기록하지만 Flutter는 거부한다. 정상적인 2재료·2단계 바나나 우유는 현재 최소 개수 정책으로 422가 된다.

이는 HTTP 성공·사용 횟수 차감·편집 가능한 모양과 조리 내용의 정확도가 별개임을 보여 준다. unverified 표시를 정확한 내용으로 세지 않아야 하며, 단순한 요리를 억지로 3재료로 늘려 통과시켜서도 안 된다.

재현: `deno run tools/test/english_quality_probe.ts`. 결과: `.artifacts/english-quality-probe.json`.
관련 Deno 회귀 37개는 통과했다. 이 통과율은 실제 서비스 성공률이 아니다.

## USB 실기기 평가 절차

사용자가 로그인된 USB 휴대폰으로 평가하기로 선택했다. 재연결 후 ADB 승인 연결을 확인했다. 휴대폰 모델 SM-G977N, Android 12, 설치 패키지 `com.kyoutube.app`, versionName 1.0.1, versionCode 54다. 연결 상태는 `ready_for_manual_app_review`다. 이는 설치 버전 확인 결과이며 로그인 상태나 영어 기능의 성공을 검증한 결과가 아니다.

Windows의 삼성 Android ADB Interface 및 USB Composite/Connectivity 장치가 모두 정상이다. 사전 표본 및 결과 입력 양식은 `tools/test/english-phone-cases.csv`에 준비했으며 아직 기능 평가 결과는 입력하지 않았다. 현재 사용 가능한 도구에는 휴대폰 화면 조작 기능이 없어 사용자가 앱을 조작하고 결과를 제공해야 한다. 첫 평가 항목은 K01 `bibimbap`으로, 영어 검색 결과에서 조리 영상을 선택하고 영어 초안 생성 결과·소요 시간·선택 영상 URL을 확인한다.

삼성 휴대폰 설정 안내: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7회 누름 → 개발자 옵션 → USB 디버깅 켜기. USB를 다시 연결하고 잠금을 해제한 상태에서 이 PC의 디버깅 허용 창을 승인한다. 메뉴 이름은 기기 버전에 따라 다를 수 있다. 승인 후 기존 로그인 앱의 버전을 확인하고 테스트한다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/test/phone-review-status.ps1
```

이 스크립트는 연결 상태·모델·Android·설치 앱 버전만 읽는다. 앱 재설치·데이터 초기화·토큰 추출·계정 등급 변경을 하지 않는다. 연결 후 앱에서 로그인, 영어 설정, 잔여 AI 한도를 확인한다. 한도를 우회하거나 실사용 계정의 정책을 변경하지 않는다.

## 90% 목표 평가 기준

1. 사전에 고정한 검색어 40종을 한식·서양식·채식·베이킹·간단 요리 각 8종으로 나눈다. 실패한 항목을 표본에서 빼지 않는다.
2. 검색 성공: 영어 요청이 전송되고, 상위 5개에 해당 음식의 실제 조리 영상이 하나 이상 있으며 영상 접근이 가능함.
3. 초안 성공: 선택 영상의 설명/자막 문맥을 받아 첫 사용자 요청에서 60초 이내 영어 편집 초안이 나타남. 내부 보완 여부·총 시간·한도 거절·서버 오류를 따로 기록.
4. 조리 정확도: 원문과 대조해 핵심 재료 누락/추가, 수량·단위, 온도·시간, 단계 순서, 인분을 확인. 확인되지 않은 값은 정답으로 세지 않는다. 중대한 계량/가열 모순은 해당 레시피 실패로 판정.
5. 최종 성공: 검색·초안·정확도를 모두 통과한 사례 / 전체 사전 표본. 설명만 있는 경우와 자막 추가 경우, 무료/유료 모델을 각각 분리한다.

40개 중 36개 성공은 관측값 90%지만 Wilson 95% 하한은 약 76.95%다. 예를 들어 40/40 또는 97/100이면 하한이 각각 약 91.24%·91.55%가 된다. 이 역시 표본 대표성과 독립성이 전제이며 실제 조리 실험을 대신하지 않는다.

## 우선 보강 제안

1. 두 실제 검색 경로에 현재 앱 언어를 연결하고 화면부터 서버 파라미터까지 회귀 검증.
2. 서버·Flutter의 성공 조건을 일치시키고 언어·중복·원문 수치·단계 연결 검증 추가.
3. 충분한 근거가 없는 영상은 확인 항목을 분명히 표시하고, 설명/자막 보완 후 재평가.
4. 검색 언어·모델·앱/함수 버전·자료 유형별 성공 지표 추가 후 위 실기기 표본 평가.

이번 문서는 진단 결과이며 품질 기준 변경이나 운영 배포를 수행했다는 뜻은 아니다. 편집 실행 취소/다시 실행 아이콘은 별도 사용자 요청으로 소스에 추가했으며 기존 v54 AAB는 변경하지 않았다.
