# 레시피 스카우트 제휴 상품 연결 안내

작성: 2026-09-19. 상태: DB 0065·운영 웹·v76 서명 AAB 반영 완료. 실제 제휴 상품은 아직 등록하지 않았습니다. 자세한 기록은 [v76 배포 기록](release-v76.md)을 참고하세요.

> 2026-09-24 개발 확장: 쿠팡과 개별/선택/일괄 관리, 검색, 휴지통, 이력은 [새 카탈로그 관리 안내](affiliate-catalog-management.md)를 참고하세요. 이 확장은 운영 미반영 상태입니다. 아래 v76 기록은 당시 배포 내역입니다.

## 연결 구조

장보기 도우미 → 구매처 찾기 → 재료 이름과 일치하는 제휴 상품 → 사용자가 링크 선택 → 네이버 판매처 또는 YouTube 상품 태그 영상.

네이버는 크리에이터 계정으로 발급한 실제 제휴 링크를 원문 그대로 사용합니다. Google 쇼핑 검색에는 임의의 수수료 코드를 붙이지 않습니다. 구글 측 지원 범위는 자격을 갖춘 운영자 본인 채널의 YouTube Shopping 상품 태그 영상 연결입니다. 영상 방문 자체는 수익이 아니며 태그를 통한 인정 구매가 필요합니다.

일반 네이버·Google 검색은 계속 사용할 수 있습니다. 제휴 상품 조회 장애가 검색·구매 기록을 막지 않습니다. 클릭을 구매·수익으로 기록하거나 조리 재고를 차감하지 않습니다. 상품 이미지는 사용 권한이 확인되지 않아 복제하지 않으며 상품명·규격·고지·링크만 표시합니다. 정산 API 연결은 없으며 각 플랫폼에서 확정 실적을 확인합니다.

## 먼저 직접 할 일: 네이버

1. [크리에이터 가입 안내](https://help.naver.com/service/30027/contents/23014?osType=COMMONOS)를 열고 네이버 계정으로 브랜드커넥트에 로그인합니다. **크리에이터** 가입을 선택합니다. 캠페인사/판매자 가입과 구별하세요.
2. 공식 화면에서 약관·본인 확인을 진행하고 스페이스를 만듭니다. 가입 과정에서 지원 채널 연결을 요구하면 본인이 운영하는 채널을 사용합니다. 유튜브 연결 자체가 레시피 스카우트 앱·웹 등록이나 수수료 인정을 뜻하지는 않습니다. 앱·웹 등록 가능 여부와 실적 인정은 아래 문의로 별도 확인합니다. [스페이스 안내](https://help.naver.com/service/30027/contents/23016?osType=COMMONOS)
3. 정산 정보가 요구되면 본인 또는 사업자 정보를 공식 화면에 직접 등록합니다. 비밀번호·인증번호·계좌번호는 레시피 스카우트나 채팅에 입력하지 않습니다.
4. 아래 문의문을 네이버 고객센터에 보내 독립 앱·웹 게시와 실적 인정 여부를 확인합니다. 허용 범위가 확인되기 전에도 제휴 상품 초안은 준비할 수 있지만 공개하지 않습니다.

> 레시피 스카우트라는 식자재 장보기 지원 Android 앱과 웹(https://recipe-scout-workspace.web.app)을 운영합니다. 로그인한 회원에게 재료에 맞는 제휴 상품을 표시하고, 회원이 버튼을 누르면 쇼핑 커넥트에서 발급받은 링크를 수정 없이 외부 브라우저로 열고자 합니다. 수수료 안내를 링크 바로 위에 표시합니다. 이 앱·웹 게시가 허용되며 구매 실적·정산 대상인지, 별도 등록·심사나 지정 고지 문구가 필요한지 알려 주세요.

5. 쇼핑 커넥트에서 **상품 찾기 → 상품 선택 → 링크 발급 → 링크 복사**를 진행합니다. 첫 상품은 춘장·간장·식용유처럼 장보기 재료와 연결하기 쉬운 3~5개면 충분합니다. [공식 발급 안내](https://help.naver.com/service/30027/contents/24104?osType=COMMONOS)
6. 네이버 답변과 발급 링크를 준비합니다. 현재 앱은 HTTPS `naver.me` 및 `brandconnect.naver.com` 링크만 받습니다. 다른 공식 도메인으로 발급되면 링크를 임의 변환하지 말고 도메인 검증을 추가한 후 사용해야 합니다. 상품별 수수료율·정산 조건은 해당 공식 화면에서 확인합니다.

## 직접 할 일: 구글 / YouTube

1. 본인 채널의 [YouTube Studio](https://studio.youtube.com)에 로그인합니다.
2. **수익 창출(Earn)**에서 YouTube Shopping 제휴 프로그램 참여 가능 여부를 확인합니다. 한국은 지원 지역이지만 YPP 등 자격 충족이 필요하며, 현재 채널이 자격을 갖췄는지는 확인하지 않았습니다. [공식 자격·가입 안내](https://support.google.com/youtube/answer/13376398?hl=ko)
3. 참여 항목이 있으면 공식 화면에서 약관을 확인하고 가입합니다. 없다면 자격 요건을 먼저 충족해야 하며 앱 코드로 이를 대체할 수 없습니다.
4. 본인이 운영하는 영상에 관련 상품 태그를 추가합니다. [YouTube Shopping 안내](https://support.google.com/youtube/answer/12257682?hl=ko)
5. 실제 상품 태그가 표시되는지 확인한 뒤 영상 주소를 준비합니다. 단순 Google 검색 주소나 다른 사람의 영상으로 운영자 수익이 생긴다고 표시하지 않습니다.

## 배포 후 앱에서 할 일

1. 관리자 계정 로그인 → 2단계 인증 → 회원 관리자 → **제휴 상품 관리**.
2. 화면의 **가입·연결 순서**에서 위 공식 안내를 다시 열 수 있습니다.
3. **제휴 상품 추가**에서 네이버 또는 YouTube를 선택합니다.
4. 상품명, 규격·브랜드, 재료 이름·별칭, 실제 발급 링크 또는 영상 주소를 입력합니다. 별칭 예: `춘장, 검정콩장, black bean paste`. 재료 이름은 대소문자·앞뒤 공백을 제외하고 정확히 일치할 때 연결됩니다. 최대 20개 별칭, 재료당 최대 6개 상품을 이름순으로 표시합니다.
5. 초안으로 먼저 저장할 수 있습니다. 공개하려면 허용 근거·확인일을 기록하고 실제 확인된 **모바일/웹** 위치만 체크합니다. YouTube는 본인 채널·가입 완료·상품 태그 확인 결과를 기록합니다. 체크는 플랫폼의 승인 요청을 대신하지 않습니다.
6. **공개 중**을 켜고 저장합니다. 저장 후 30일이 지나면 자동으로 숨겨지므로 링크·재고·정책을 다시 확인하고 저장합니다. 중단할 때는 공개 스위치를 끄고 저장합니다. 링크를 바꾸면 기존 공개·허용 체크가 초기화됩니다.
7. 일반 회원 화면에서 해당 재료의 **구매처 찾기**를 열어 규격과 고지 문구가 표시되고 실제 목적지로 이동하는지 확인합니다. 본인 구매를 통한 수익 테스트는 각 프로그램 약관을 먼저 확인해야 합니다.
8. 수익은 네이버/YouTube의 확정 실적으로 확인합니다. 주문 취소·반품 등은 플랫폼 정산 정책에 따릅니다. 앱의 수동 구매 기록은 제휴 수익 증빙이 아닙니다.

## 배포·운영 참고

- 신규 DB: `0065_shopping_affiliate_offers.sql` (0060의 관리자 MFA 검사 사용). 기존에 준비한 0064는 별도 직원관리 변경이며 이번 제휴 기능의 필수 의존성은 아닙니다.
- 관리자 RPC만 쓰기 가능, 일반 회원은 공개·유효한 상품의 제목/규격/링크만 조회. 승인 근거·관리자 ID는 노출하지 않습니다. 미로그인·익명 회원 조회 불가.
- 관리자 편집은 revision 충돌을 검사합니다. 공개 설정은 운영자의 실제 확인에 근거해야 하며 시스템이 네이버 승인이나 상품 태그 유무를 자동 검증하지는 않습니다.
- 사용자 승인 후 운영 DB 0065 적용·웹 배포·v76 서명 AAB 생성을 완료했습니다. Google Play 업로드와 실제 제휴사 가입/승인은 별도 단계입니다.
- 기본 구조에 신규 유료 API는 없습니다. 기존 DB/호스팅 사용량은 증가할 수 있습니다.
