## 구현

- 구매처 찾기에서 네이버 일반 검색과 네이버 제휴 상품을 숨깁니다. 저장된 링크·관리자 자료는 삭제하지 않습니다.
- 공개된 쿠팡 제휴 상품을 일반 검색보다 먼저 보여 줍니다. 수수료 안내와 발급 링크를 유지합니다.
- 쿠팡 일반 검색을 추가하고 Google 쇼핑을 유지합니다. 사용자가 입력한 상품명·규격만 검색하며, 레시피 필요량은 검색 규격에 자동 추가하지 않습니다.
- 쿠팡 제휴 상품이 없으면 준비 중 안내를 표시합니다. 일반 검색은 파트너스 발급 링크가 아니므로 수익 추적 연결 완료로 취급하지 않습니다.
- 웹·Android 공통 화면에 적용하며 검색 실패 시 링크 복사·재시도, 계정 변경 보호를 유지합니다.
