## 사용자 변경 사항

- 레시피 상세의 셰프 작업실·장보기 준비 버튼을 같은 중요도로 유지하면서 높이를 줄였다.
- 셰프 재료 수정·단가 바로 수정에 무게·부피·개수·포장 단위 선택과 사용자 단위 직접 입력을 추가했다.
- 자동 환산이 안 되는 단위는 구매 1단위에 해당하는 사용량을 입력한다. 예: 1팩=400g.
- 기준은 재료별 원가·수율 계산과 작업/버전에 반영된다. 단위를 변경하면 이전 기준을 초기화한다.
- 미입력 기준을 임의로 추정하지 않는다. 중간 작업 저장은 가능하지만 원가는 미완성으로 남고 매출 확정은 차단된다.
