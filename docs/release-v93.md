## 반영 내용

품명의 일부·여러 단어 검색과 선택, 제휴 상품이 없을 때 일반 쿠팡 검색, 거래처·상품·재고 즉시 등록 후 업무 복귀, 로그인·MFA 복귀, 요청서 수정·재승인 연결, 중복 제휴 상품·편집 충돌 해결, 관련 재고·예약 자료 탐색을 반영했다. g↔kg·mL↔L 재고 연결 환산과 실제 재고 단위의 예약을 지원한다.

서버 변경 0082와 0083을 한 트랜잭션으로 적용했다. 기존 함수 정의·이력을 사전 기록하고 적용 직전 다시 비교했다. 사용자 자료는 변경하지 않았다. 별도 Edge Function 재배포는 필요하지 않았다.
