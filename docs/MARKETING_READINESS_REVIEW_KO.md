# 홍보 기능 사용 가능 여부 검토

검토일: 2026-10-10, 한국 시간. 대상: GitHub의 홍보 자동화 코드, 운영 함수 목록 및 내려받은 운영 함수 소스, GitHub Actions 실행 기록, 사무실 개발 소스 통합본.

## 판단

홍보 기능은 개발·테스트 가능한 상태이며 자동 작업도 운영 중입니다. 다만 현재 복구한 운영 웹과 기존 Android v99에는 새 홍보 관리 화면이 포함되지 않았으므로 사용자 화면을 통한 전체 흐름의 사용 가능 여부는 아직 확인되지 않았습니다. 자동 작업의 성공 기록만으로 실제 홍보 영상이 공개되었다고 판단할 수 없습니다.

## 확인된 상태

- GitHub 변수 `MARKETING_ENABLED`는 `true`입니다. 기본 브랜치의 자동 작업이 약 한 시간 간격으로 실행되고 있으며 최근 5개 실행이 성공했습니다.
- 최신 확인 실행은 [2026-10-10 실행 기록](https://github.com/guige01-guinsa/kyoutube/actions/runs/38034892955)입니다. 게시 작업 단계가 실제 실행됐지만 이 실행에서 새 영상 업로드를 알리는 로그는 확인되지 않았습니다. 예약할 대상이 없으면 작업은 업로드 없이 성공할 수 있습니다.
- 게시 범위는 `MARKETING_PRIVACY=private`입니다. 현재 설정에서는 영상이 올라가도 일반 이용자에게 공개되지 않습니다.
- 운영 Supabase에 `marketing_generate` 함수가 ACTIVE 상태로 등록돼 있습니다. 운영 함수 소스에도 `MARKETING_GENERATION_ENABLED`가 정확히 `true`일 때만 생성하도록 하는 조건이 있습니다. 이 설정의 현재 값과 실제 관리자 생성 성공 여부는 이번에 확인하지 않았습니다.
- 생성·예약·취소에는 별도의 `marketing_admins` 등록과 관리자 2단계 인증(AAL2)이 필요합니다. 일반 앱 관리자라는 사실만으로 홍보 권한이 생기는 구조는 아닙니다.
- 사무실 개발 브랜치에는 계정 화면의 ‘마케팅 자동화’ 메뉴, 중앙 라우트, 홍보 화면·서버 함수·DB 정의·작업 도구·테스트를 함께 보존했습니다.

## 제공되는 기능과 범위

요리 영상 검색, 장보기 목록 정리, 보유 재료로 레시피 검색의 세 주제로 한국어 초안을 생성합니다. 제목·설명·3개 장면을 확인한 뒤 예약을 승인하거나 취소할 수 있습니다. 생성 한도는 최근 24시간 전체 5회이며 실패한 AI 호출도 한도를 사용합니다. 예약은 최소 5분 뒤부터 30일 이내입니다.

영상은 세 장면으로 구성된 24초 세로 무음 카드 형식입니다. 실제 앱 화면 녹화·음성·음악·다른 SNS 게시 기능은 현재 구현에 없습니다. 초안 내용을 화면에서 수정하는 편집 기능도 없습니다. 업로드 후 조회·좋아요를 집계하지만 설치·가입·재방문 분석은 구현되어 있지 않습니다.

영상 업로드 결과가 불확실하면 `needs_review`로 보류하고 자동 재업로드하지 않습니다. 채널 핸들을 확인하고 인증된 계정이 해당 채널을 소유하는지 검사합니다.

## 검증 근거

이번 복제본에서 홍보 worker 단위 테스트 8개와 Edge Function 타입 검사를 통과했습니다. [기존 Marketing Quality 실행](https://github.com/guige01-guinsa/kyoutube/actions/runs/37931140593)도 DB 관리자 격리·예약 권한·한 번만 작업 가져오기·불확실한 업로드 보류·생성 한도와 영상 렌더링 검사를 통과했습니다. 실제 운영 관리자 계정으로 초안 생성·승인·업로드를 수행한 종단 검사는 이번에 수행하지 않았습니다.

## 실제 사용 전 남은 확인

1. 사용자에게 배포할 정상 소스에 홍보 화면이 통합됐는지 확인합니다. 이 개발 브랜치는 개발용이며 push 자체로 웹·앱을 배포하지 않습니다.
2. 실제 운영 계정의 홍보 관리자 등록과 2단계 인증을 확인합니다.
3. 운영 생성 활성화 설정, AI 모델과 키·예산을 확인하고 관리자 화면에서 초안 1개를 생성합니다.
4. 검토한 초안을 비공개로 예약해 올바른 채널에 한 번만 올라오는지 확인합니다.
5. 공개 홍보가 필요하면 비공개 시험 결과를 확인한 뒤 별도 승인을 받아 공개 범위를 변경합니다.

이번 검토에서 운영 DB·함수·자동화 설정을 변경하거나 영상을 게시하지 않았습니다.
