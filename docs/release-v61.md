## 사용자 변경 사항

- 기존 제목·설명 기반 자동 초안과 월간 프리미엄 영상 분석 중 생성 방식을 선택한다. 화면 진입만으로 사용 횟수를 차감하지 않는다.
- 월간 프리미엄은 한국 시간 기준 월 20회, 최대 20분의 공개 일반 영상을 분석할 수 있다. 무료·연간 베이직은 영상 분석을 사용할 수 없다.
- 영상 분석 시작 시 월 영상 횟수에 포함되며, 초안 성공 시 기존 전체 AI 사용 한도에도 1회 반영된다. 실패한 분석도 제공사 비용이 발생할 수 있어 시작된 요청은 포함하고 자동 재시도하지 않는다.
- 확인되지 않은 분량·시간 등을 한글·영어로 안내하고 편집 초안에도 확인 표시를 보존한다.
- 영어 초안 편집의 확인 안내 제목도 영어로 표시한다.

## 운영 배포

- 프로젝트: `dfczeudklykypysiseck`.
- DB `0050_premium_video_analysis`만 적용했고 변경·검증·마이그레이션 이력을 동일 트랜잭션에 기록했다. 저장된 SQL과 로컬 원본 일치.
- DB 원본 SHA-256: `2888fb7d7e74f5a8b0e8ceeb0d4aea08c405318c9f5b21c740e31bb9aac9e8f3`.
- 0047·0048은 기존 MFA 보류 상태를 유지했다. 일반 db push로 함께 적용하지 않았다.
- `GEMINI_API_KEY` 등록과 `VIDEO_ANALYSIS_ENABLED=true`를 관리 API의 SHA-256 일치로 확인했다. 키 값이나 해시 자체는 로그에 기록하지 않았다.
- 새 함수 `ai_youtube_video_assistant`: 최종 실행 버전 **2**, ACTIVE, `verify_jwt=true`. 명시적인 소스 배포 명령은 이 함수 1개에만 실행했다.
- 다운로드한 운영 코드의 요청 생성·핸들러·진입점·공유 코드 등 7개 파일이 로컬 소스와 바이트 단위로 일치했다.
- Supabase 비밀값 설정 3회로 기존 함수의 실행 버전도 각각 3 증가했다. 이는 플랫폼의 환경 갱신 동작이며, 기존 함수의 소스 배포 명령은 실행하지 않았다. 기존 JWT 설정과 ACTIVE 상태를 확인했다.
- 최초 추가 검사에서 원시 사용량 테이블의 명시적 SELECT 권한이 로컬과 달라 트랜잭션이 롤백됐다. 운영에는 기본 테이블 권한이 있으나 RLS 활성화·정책 0개로 접근이 거부된다. 실제 authenticated 역할 조회가 0행임을 확인하고 유효 RLS 접근 검사로 검증 절차를 수정해 적용했다. 마이그레이션 원본을 수정하거나 적용 도중 데이터를 변경하지 않았다.
- 일반 회원은 사용 예약/제공사 시작 RPC를 실행할 수 없고, 익명 사용자는 개인 사용량 RPC도 실행할 수 없다. 함수에 세션 없이/익명 역할로 접근하면 HTTP 401로 차단된다.
