# 기존 영상으로 만드는 음식 백과형 재편집

기존 60초 스토리 제작은 바꾸지 않는다. 검토된 새 원고를 별도 초안으로 저장하고,
관리자가 출처 검토 및 제작 비용을 승인했을 때만 기존 render 작업으로 실행한다.
기존 업로드 영상이나 원고, 비용 기록을 덮어쓰거나 삭제하지 않는다.

## 명시적인 선택과 원본 고정

새 초안의 brief에 다음 형식의 **독립된 한 줄**이 있어야 한다.

`[ENCYCLOPEDIA_REEDIT:<원본 회차 UUID>:<원본 한국어 MP4 SHA-256>]`

원본 회차는 같은 시리즈에 속하고 preview 또는 uploaded 상태여야 한다.
현재 지원하는 원본 레이아웃은 `[APP_DEMO:bibimbap-v1]`을 사용한 60초,
720×1280 영상뿐이다. 다른 레이아웃을 이 형식으로 가장하면 안 된다.
MP4 경로·파일 해시·실제 프레임 수·음성 트랙을 음성 API 호출 전에 검사한다.
원본이 바뀌었거나 조건에 맞지 않으면 실패하며 새 삽화를 대신 생성하지 않는다.

## 출력과 한계

- 새 재편집은 한국어 chapters의 전체 문장만 읽고 같은 글을 위로 이동시킨다.
- 보관된 번역 원고는 호환성을 위해 남길 수 있지만 영어·스페인어 음성이나 영상은 생성하지 않는다.
- 한국어 단독 완료 규칙의 DB 마이그레이션을 먼저 적용해야 한다. 기존 3개 언어 회차는 그대로 보존한다.
- 음성은 OpenAI `gpt-4o-mini-tts`, 기본 제공 `coral` 음색이다. 특정 인물을 모방하지 않는다.
- 실제 사람 녹음이 아닌 AI 음성임을 화면과 업로드 설명에 밝힌다.
- 각 문단을 최대 400자 단위로 문장 경계에서 나누고 실제 WAV 길이로 화면 시간을 정한다.
- 문장 단위 이동이며 단어별 강제 정렬이나 노래방식 강조 기능은 아니다.
- 한국어 검토본 최대 15분, 파일별 최대 100 MiB, 기존 작업의 20분 임대와 예산 검사를 유지한다.
- 원본 삽화 파일은 과거 작업 종료 시 제거되었다. 완성 MP4를 재사용하므로 원래 상하단 자막을
  불투명한 제목·본문 패널로 가린다. 가운데 삽화는 그대로이며, 가린 부분의 원본을 복원한 것은 아니다.
- 기존 60초 이미지·음악 순환을 반복한다. 음악은 같은 트랙이며 내레이션을 위해 음량만 낮춘다.
- 출력은 검토용 Storage 영상뿐이다. 유튜브 업로드는 별도 검토·승인 작업이다.

## 비용·권한·실패 처리

기존 `render_usd` 예약액과 일일 작업 수·월 예산을 그대로 적용한다.
예상 예약액은 실제 청구 상한이 아니다. 이미지 생성과 텍스트 모델 호출은 하지 않는다.
기존 제작 키의 Speech 쓰기 권한과 TTS 모델 접근 권한이 필요하다. 키 권한을 자동 확장하지 않는다.
403/429 등의 음성 실패는 안전한 상태 코드만 기록하고 자동 재시도하지 않는다.
실패 후 다시 실행하기 전에는 이미 발생한 음성 비용을 확인한다.

전체 원고·음성·미리보기·비밀키는 공개 저장소에 넣지 않는다.
새 원고와 허용된 원본 해시는 관리자 환경에서만 넣는다.
