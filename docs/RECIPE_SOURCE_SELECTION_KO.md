# 읽을 수 있는 원문 우선 선택

영상 검색, 재료 검색, 추천 검색은 공통 `youtube_search` 서버를 사용한다.
검색 API의 짧은 소개문으로 원문 존재를 판단하지 않는다. 기존 영상 길이 일괄 조회에
`snippet`을 포함하여 전체 설명을 받는다. 재료와 계량, 조리 안내를 확인할 수 있는
설명만 검색 결과에 포함한다. 한국어·영어·스페인어의 기본 표기를 지원한다.

공통 판정은 `supabase/functions/_shared/recipe_source_eligibility.mjs`에서 수행한다.
이것은 원고 추출을 위한 사전 검사이며 사실·안전·완전성에 대한 보증이 아니다.
영상 안에만 표시된 레시피, 외부 주소만 있는 설명, 지원하지 않는 표기는 제외될 수 있다.
검색 결과가 줄어들 수 있으며, 설명란에 레시피를 보강하면 다음 검색에서 다시 판정된다.
유료 AI, 자막 다운로드, 동영상 다운로드, 외부 사이트 차단 우회는 사용하지 않는다.
YouTube 또는 네트워크 오류는 검색 오류로 처리하고 영구 제외 명단에 넣지 않는다.
저장된 레시피나 사용자가 만든 작품을 삭제하지 않는다.

제작소는 요청한 영상을 먼저 확인한다. 설명 부족 또는 한국어 원문 미지원이면
같은 음식의 한국어 후보를 한 번 검색하고 최대 5개 영상의 설명을 일괄 확인한다.
음식명이 제목에 맞고, 공통 사전 검사를 통과하며, 인분·재료·조리 순서를 확인할 수
있는 첫 후보만 선택한다. 조회수가 높다는 이유로 다른 음식을 선택하지 않는다.
제목에 적힌 유명인 이름 대신 YouTube가 반환한 채널 이름으로 출처를 표시한다.

원문 선정 후 AI는 선택한 한 설명 안의 줄 범위만 찾는다. 재료와 조리 문장은
선택한 원문에서 그대로 복사한다. 여러 영상의 레시피를 섞거나 수치를 추측하지 않는다.
AI 결과가 불완전하면 추가 유료 호출 없이 중단한다. 후보가 없으면 AI 호출도 하지 않는다.
변경한 출처와 처음 요청한 주소는 원고 검토 화면에 표시하고, 기존 원문 검토·음성
선택·제작 비용 확인 절차를 유지한다. 공개 게시나 유료 자동 재시도는 추가하지 않는다.

이 변경은 새 작업의 원문 선택 경로를 보완한다. 과거 실패 작업을 성공으로 바꾸거나
예상 예약액을 실제 청구액으로 간주하지 않으며, 기존 예약을 지우거나 재사용하여
비용 확인을 우회하지 않는다. 실패한 기존 작업 재개는 별도 확인이 필요하다.

검사: 공통 다국어 설명 판정, 링크 전용 설명 제외, 전체 설명 기준 일괄 검색,
일시 장애 후 재검색, 대체 원문 출처 증거, 한 영상만 사용, 최대 한 번의 유료 원고
호출, 후보 없을 때 유료 호출 없음, 웹에서 변경 이유·원주소·검토 상태 표시.
