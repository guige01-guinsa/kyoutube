# 비공개 문단 음성 보관과 재개

한국어 백과사전 재편집 작업은 문단 음성을 생성할 때마다 `story-speech-cache` 비공개 저장소에 먼저 저장하고 검증합니다. 이후 별도로 승인한 재제작 작업에서는 같은 회차의 동일 문장·언어·모델·목소리·속도·음성 지시를 해시로 비교해 재사용합니다. 문장이나 음성 설정이 바뀌면 다른 음성으로 취급합니다. 다른 회차의 음성을 섞지 않습니다.

저장·검증에 실패하면 다음 유료 요청을 보내지 않습니다. 저장된 파일이 없어졌거나 체크섬이 다르면 자동으로 재생성하지 않고 검토 상태로 멈춥니다. 업로드는 됐지만 확인 응답만 유실된 경우에는 다음 승인 작업에서 파일을 검사해 이어갑니다. 같은 작업 안에서 실패한 음성 요청을 자동 반복하지 않습니다.

## 권한과 한도

- 저장소는 비공개이며 관리자 및 2단계 인증을 통과한 사용자만 읽을 수 있습니다. 일반 사용자와 비로그인 사용자는 접근할 수 없습니다. 클라이언트의 추가·수정·삭제는 금지합니다.
- 서버 작업의 유효한 실행권한, 관리자 유지 여부 및 제작 활성 상태를 매 문단마다 다시 확인합니다.
- 파일당 12 MB, 전체 음성 보관 예약량 192 MB로 제한합니다. 미완료 문단은 12 MB를 보수적으로 예약합니다. 용량 부족 시 새 음성 생성 전에 멈추며 기존 파일을 자동 삭제하지 않습니다.
- 이 한도는 별도 저장소 사용량이나 실제 청구액을 보장하지 않습니다. 기존 일일·월간 제작 예약 한도는 그대로 적용됩니다. 예약액은 실제 청구액과 다릅니다.
- 원고, 음성, 키는 공개 저장소나 작업 로그에 기록하지 않습니다. 공개 코드에는 해시 계산 및 권한 규칙만 포함됩니다.

## 운영과 재개

`20261025150000_speech_cache_story_studio.sql`을 승인 후 대기·진행 작업이 없는 상태에서 적용합니다. 서버 코드만 먼저 반영돼도 DB 구성이 없으면 새 음성 비용이 발생하기 전에 안전하게 중단합니다.

이 변경은 자동 재시도나 자동 유료 제작을 켜지 않습니다. 실패한 회차는 기존처럼 관리자가 원인과 비용을 검토한 뒤 재제작을 별도로 승인해야 합니다. 현재 웹 화면에 실패 회차 재개 버튼이 없는 경우 운영자가 회차 상태·버전·진행 작업을 확인하여 복구해야 하며, 새 웹 버튼을 배포한 것으로 간주하지 않습니다. 새로 승인된 같은 회차 제작 작업에 저장된 문단 재사용이 자동 적용됩니다.

기존 실패 실행에서 삭제된 임시 음성은 복구할 수 없습니다. 이 보관 기능 적용 후 성공적으로 저장된 문단부터 재사용할 수 있습니다. 기존 영상·유튜브 게시 상태·예산 설정은 변경하지 않습니다.

## 무과금 검증

`story_studio_speech_cache.test.mjs`는 합성 WAV와 가짜 저장소로 부분 실패·재개·손상·권한/저장 실패를 검사합니다. `story_studio_database.test.mjs`는 격리 DB에서 관리자/MFA/RLS, 실행권한, 동일 작업 재과금 방지, 용량 및 재개 소유권을 검사합니다. 실제 OpenAI 호출이나 유튜브 업로드는 하지 않습니다.
