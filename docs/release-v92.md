## 반영 내용

상품 카드마다 표시하던 ‘쿠팡 제휴 상품’ 제목과 제휴 수수료 안내를 제거하고, 화면 하단에 공통 안내를 한 번만 표시한다. 기본 글자 크기는 12이며 시스템 글자 확대를 유지한다. 목록과 별도 영역이므로 스크롤해도 안내가 하단에 표시된다. 공개 쿠팡 상품이나 선택한 쿠팡 상품이 없는 화면에서는 안내를 표시하지 않는다.

개인 장보기·업소 메뉴 구매 준비·구매 요청서 편집·승인 후 쿠팡 구매·구매처 선택·수동 재료의 쿠팡 상품 찾기·관리자의 실제 노출 확인에 반영했다. 가격·구매량 계산·제휴 주소·승인·입고 로직은 유지했다. 이번에는 DB 변경이나 서버 함수 재배포가 필요하지 않았다.

[쿠팡 파트너스 공식 가이드](https://partners.coupangcdn.com/partners-guide/partners-guide-20250714121952.pdf)는 경제적 이해관계를 이용자가 인식할 수 있도록 표시할 것을 안내한다. 공통 안내를 유지한 이유이며, 개별 운영 심사 결과를 보장하는 것은 아니다.
