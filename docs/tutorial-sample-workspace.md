# 튜토리얼 샘플 작업실

2026-09-18 사용자 승인으로 운영 웹 배포와 v72(1.0.1+72) 서명 AAB 생성·검증을 완료했다. DB·서버 함수 변경은 없다. [릴리스 기록](release-v72.md).

## 사용 방법

체험 튜토리얼에서 원하는 실습을 연 뒤 **샘플로 바로 체험**을 누른다. 처음 실행할 때 필요한 자료가 자동 준비된다. 안내에 따라 값을 수정하고 **연습 내용 저장** 또는 **저장하고 다음 체험**을 누른다. 저장은 기기/브라우저 안의 연습 공간에만 적용된다. 닫았다 다시 열어 이어 할 수 있고, 상단 초기화 버튼으로 해당 언어의 모든 샘플을 되돌릴 수 있다. 초기화에는 확인창이 있으며 실제 자료와 학습 완료 기록은 지우지 않는다.

24개 실습에 각각 구체적인 변경 예시와 결과 안내가 있다. 어떤 실습부터 시작해도 기본 자료가 준비되어 있다. 기존 **예제로 연습**(짧은 메모리 예제)과 **내 자료로 시작**(실제 업무 화면)도 유지한다.

| 영역 | 준비되는 자료와 할 수 있는 일 |
| --- | --- |
| 일반 사용자 5개 | 검색용 레시피 3개, 수량/조리 단위/순서/메모 편집, 초안 검토, 별도 구매량, 구매 완료·반복 준비 |
| 전문가 조리·경영 8개 | 원가 입력이 갖춰진 메뉴 5개, 기준/목표 인분, 재료별 수율·구매 규격·단가, 추가 비용, 가산율, 날짜별 매출 8건, 각 메뉴 비교 버전 2개, 준비된 AI 분석 결과 검토 |
| 전문가 구매 6개 | 당근·양파·두부 구매 목록, 가상 업체 4곳, 재료별 후보 최대 3곳, 세 가지 최적화 기준, 업체별 요청 초안, 수정·미리보기·실제 샘플 PDF, 모의 발송, 상태가 다른 대장 3건, 재요청 |
| 공급업체 5개 | 가상 업체 프로필, 원본 일러스트가 포함된 상품 6개, 상품명·이미지·분류·원산지·지역·포장량·단가 편집, 공개 전 검토와 모의 공개 |

자료는 한글과 영어별로 따로 저장하며 샘플 금액은 두 언어 모두 KRW이다. 샘플 매출일은 처음 자료를 만든 날 기준이고, 예시 업체의 단가·평점·배송 조건은 시장 정보가 아니다. 사진 대신 자체 제작한 식재료 일러스트 6종을 사용한다.

## 연결된 흐름

구매 목록의 선택/수량 → 내 거래처 우선 표시 → 재료별 후보 → 최소 거래처/최저 금액/평점 비교 → 업체별 요청서 → 수정·PDF·모의 발송 → 대장 → 새 요청 초안으로 연결한다.

- 비교는 기존 `createProcurementPlan`을 사용한다. 기본 각 1kg일 때 배송비 포함 16,000원/8,000원/25,000원이다. 포장 수량은 구매 규격에 맞춰 올림 계산한다.
- 원가와 인분은 기존 `ChefRecipe`, 일/주/월 범위는 `ChefSalesRange`를 사용한다. 매출은 당시 단가/원가를 저장하므로 이후 메뉴 수정이 과거 매출을 바꾸지 않는다.
- 조리 단위는 사용자가 편집한다. 샘플 구매 수량은 g/kg 간 환산을 지원하고 별도로 보관하며 인분/수율 변경으로 자동 수정하지 않는다. 조리 재고 차감은 없다.
- 재요청은 기존 `SupplierRequest.repeat`를 사용하여 가격과 납품일을 비운다. 사용자가 새 조건을 확인해 입력해야 저장할 수 있다.
- PDF는 기존 요청서 생성기를 사용하되 모든 페이지에 **연습용 · 실제 주문 아님**을 표시한다. 웹 다운로드/기기 공유창/인쇄창은 사용자가 출력 버튼을 눌렀을 때만 열린다. 출력만으로 요청서 상태를 바꾸지 않는다.
- 모의 발송과 공개는 검토 체크를 해야 실행할 수 있다. 요청서를 다시 수정하면 발송 검토 표시를 해제한다.

## 격리와 보관

`GuideSampleStore`는 운영 repository, Supabase client, 계정·구독 provider를 사용하지 않는다. `guide_sample_records_v1_ko` / `guide_sample_records_v1_en`에 JSON 레코드를 저장한다. 요청서 ID는 `sample-`로 구분하고 URL에는 실습/샘플 번호만 사용한다. 실제 회원 DB에 샘플을 심지 않는다.

누구나 샘플 원가·매출·PDF·AI 검토를 체험할 수 있지만 실제 자료의 요금제와 서버 권한은 그대로다. AI 결과는 준비된 자료이며 AI 요청, 유료 분석 횟수 차감, 결제, 메시지 전송, 실제 공개 등록을 호출하지 않는다.

이 기기에서만 보관되므로 다른 기기나 브라우저로 동기화되지 않는다. 계정을 바꿔도 기기의 연습자료는 남는다. 실제 연락처·등록증 대신 가상 자료로 사용하도록 안내한다. 브라우저 데이터를 지우면 샘플도 지워지며 다음 진입 때 기본 샘플을 새로 준비한다. 저장 형식 손상이 있으면 새 자료로 복구하고 안내한다. 저장 실패 시 이전 저장본을 유지하고 새 입력을 재시도할 수 있게 한다.

이번 범위에서는 실제 인증서 사진/개인정보, 라이브 영상 검색/분석, 실제 상품 업로드, 실제 거래처 발송을 샘플로 수행하지 않는다. 해당 동작은 기존 **내 자료로 시작**을 통해 실제 권한 아래에서 실행한다.

## 구현과 검증 위치

- `lib/features/guide/domain/guide_sample_data.dart`: 샘플 레코드, 원가·요청·매출 연결
- `guide_sample_tasks.dart`: 24개 한영 행동 안내
- `lib/features/guide/application/guide_sample_store.dart`: 로컬 보관/복원/초기화
- `lib/features/guide/presentation/guide_sample_*.dart`: 역할별 편집과 문서 체험
- `/guide/practice/:lesson`, `/guide/practice/:lesson/pdf/:request`: 루트 연습 경로
- `assets/guide/`: 원본 그림 6개. `tools/dev/generate_guide_images.dart`로 재생성
- `test/features/guide/guide_sample_data_test.dart`, `presentation/guide_sample_page_test.dart`: 레코드/계산/격리/한영 화면/연결 흐름 검증

검증 결과는 `.artifacts/verify-tutorial-samples.json`에 기록한다. 화면·샘플 PDF는 `.artifacts/tutorial-samples/`에 보관한다. 실제 프린터 종이 출력은 수행하지 않는다.
