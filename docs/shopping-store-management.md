# 내 구매처 관리

2026-09-13. 사용자가 온라인 쇼핑몰·동네 매장·기존 협력업체를 직접 관리합니다.
장보기 도우미의 ‘내 구매처 관리’ 또는 상단 매장 아이콘에서 들어갑니다.
`/shopping-stores`는 ‘내 구매처’ 탭을 바로 열고 선택한 장보기 목록을 유지합니다.

- 구매처 추가/수정/삭제: 이름, 구매 사이트 HTTPS 링크, 담당자, 연락처, 주로 사는 재료, 주소, 개인 메모.
- ‘자주 쓰는 구매처’는 목록 위에 먼저 표시합니다. 이름·재료·메모 등으로 검색하고 즐겨찾기만 볼 수 있습니다.
- ‘구매 사이트 열기’는 사용자가 저장한 사이트를 외부 앱/브라우저에서 엽니다.
- ‘이 구매처에 요청’은 해당 구매처를 미리 선택한 요청서 편집기를 엽니다. 품목 선택 및 저장/공유는 사용자가 이어서 진행합니다.
- 등록한 구매처의 사이트 링크와 재료별 ‘자주 사는 상품’ 링크는 별도로 관리합니다.
- 개인 메모·구매처 주소·웹사이트·즐겨찾기 설정은 요청서 스냅샷과 공유 텍스트/PDF에 넣지 않습니다. 요청서의 납품 장소는 사용자가 따로 입력합니다.
- 업체 삭제 시 기존 요청서는 보존됩니다. 사용자 계정 삭제 시 구매처와 요청서가 함께 삭제됩니다.

무료/유료 로그인 회원 모두 사용합니다. 업체는 앱에 가입할 필요가 없으며, 연락처는 사용자가 직접 입력합니다.
구매처 관리를 위해 주소록 권한, 신규 외부 API, AI 호출을 추가하지 않습니다.

## 저장 및 출시

DB 0053은 기존 `shopping_suppliers`에 website/address/memo/is_favorite을 추가합니다.
0052의 사용자별 RLS, 소유자 변경 금지, 사용자당 200개 한도를 유지합니다.
HTTPS 링크 형식과 길이를 앱/DB에서 검사하고, URL에 앱 인증 정보를 추가하지 않습니다.
기존 요청서의 업체 스냅샷 형식은 유지하며, 예전 스냅샷도 읽을 수 있습니다.

사용자 승인으로 운영 DB 0051·0052·0053을 함께 적용했습니다. v62 서명 AAB 생성·검증 상태는 [v62 출시 기록](release-v62.md)을 참고합니다.
기존 보류된 0047·0048은 이번 적용 대상이 아니므로 전체 db push를 사용하지 않습니다.

## 검증 결과

- `tools/dev/verify.ps1` 완료: Flutter 3.44.8 정적 분석 오류 없음(177.5초), 전체 테스트 266개 통과·기존 선택형 미리보기 테스트 4개 건너뜀(4분 34초).
- 구매처 추가·편집·삭제, 즐겨찾기 저장/검색 정렬, 한영 360×800·글자 배율 1.15 화면, 사이트 열기 및 지정 구매처 요청서 연결을 검증했습니다.
- 개인 메모 등 관리 전용 정보가 요청서 데이터와 한영 공유 텍스트에 들어가지 않는지 확인했습니다. 기존 요청서 스냅샷도 그대로 읽습니다.
- `tools/test/run_supplier_request_contract.ps1`: 장보기·구매처 관리·구매 요청서 계약 테스트 모두 통과. 다른 사용자 조회/수정/삭제 차단, 변경 가능한 열 제한, 잘못된 URL 및 과도한 메모 차단을 확인하고 전체 트랜잭션을 롤백했습니다.
- 환경 진단에는 기존 전역 SDK PATH, Android 라이선스 상태, Windows Visual Studio 구성 경고가 남아 있습니다. 지정된 로컬 Flutter와 JDK 17로 검증했습니다.
- 후속 운영 적용 및 v62 AAB 검증은 [v62 출시 기록](release-v62.md)을 따릅니다. 실제 사이트 주문/카카오톡 전송과 휴대폰 설치는 수행하지 않았습니다. 앞서 생성한 디버그 APK는 이 확장 이전 버전입니다.
