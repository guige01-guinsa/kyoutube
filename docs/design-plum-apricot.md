# 아이보리·플럼·살구 디자인 적용 (2026-09-25)

사용자가 승인한 시안과 달리 식단 기능에 기존 녹색 테마가 적용되어 있던 문제를 수정했다. 이 문서는 적용 범위를 설명한다. 후속 승인으로 v84 운영 웹 배포·DB0072 적용·서명 AAB 생성을 완료했다. Play v84 업로드는 아직 수행하지 않았다. [최신 릴리스 상태](release-v84.md).

## 실제 반영 범위

- 공통 색상: 아이보리 배경 `#FBF8F3`, 플럼 주요 동작 `#69445F`, 살구 보조 동작 `#F4D6C0`, 옅은 플럼 선택 영역 `#F0E6EC`. 기존 기능의 공통 테마 참조에도 적용된다.
- PC: 일반 사용자·개인 작업실·공급업체·업소 공동 작업공간의 어두운 사이드바를 밝은 상단 탐색 메뉴로 교체. 기존 역할별 노출, 라우팅, 편집 이탈 방지 유지.
- 홈: 사진과 검색을 함께 배치한 PC 도입부, 모바일 세로 배치, 레시피 가져오기·직접 만들기, 사진 중심 추천 카드. 실제 큐레이션 레시피와 기존 데이터 공급자를 사용한다. 직접 만들기는 로그인하지 않은 사용자를 로그인으로 안내한다.
- 공통 제목·카드·입력칸·버튼·하단 메뉴와 개인 연구·이용 목적 선택·요청서의 남은 고정 브랜드 색상 정리.
- 식단 달력: 플럼 안내 카드, 살구 날짜 표시, 오늘 강조, 작성·확정·조리 완료 상태 표시, 날짜와 이동 버튼 묶음. 상태는 글자로도 표시하며 확정·구매 권한은 변경하지 않는다.
- 앱 안의 브랜드 표식은 새 테마를 사용한다. Android 런처 아이콘과 업로드 서명은 유지했다. 후속 배포의 릴리스 버전은 1.0.1+84다.

## 검증 결과

- 고정 Flutter 3.44.8의 최종 `flutter analyze`: 오류·경고 0.
- 필수 `tools/dev/verify.ps1` 전체 실행: 645개 통과, 조건부 4개 제외, 디자인 변경에 따른 테스트 3개 실패를 발견했다. 두 테스트는 화면이 스크롤된 다음 프레임을 기다리지 않고 클릭했고, 한 테스트는 교체된 영문 홈 제목을 기대했다.
- 실패한 3개 테스트와 영향을 받는 홈·업소 구매·식단·번역·앱 테스트를 수정 후 함께 재실행: **33개 모두 통과**. 전체 실행 로그를 성공으로 덮어쓰지 않았다.
- PC/모바일 실제 위젯 캡처를 직접 검수했다. 320px·200% 글자 및 한영 레이아웃 회귀 테스트를 포함했다.
- 주요 텍스트 대비: 흰색/플럼 8.10:1, 보조 글자/아이보리 5.00:1, 본문/살구 10.03:1.
- 기존 doctor 경고(PATH의 전역 SDK, Android 라이선스 상태, Windows Visual Studio 구성)는 그대로이며 고정 SDK로 분석·테스트했다.
