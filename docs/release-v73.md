# Recipe Scout v73 — 2026-09-18

사용자 승인으로 **구매요청서 문서형 미리보기와 PDF 중심 공유**를 운영 웹과 **1.0.1+73 서명 AAB**에 반영했다. v72 업로드 서명을 유지했다. DB·서버 함수·요금제·PDF 이용권한 변경은 없다.

## 변경 내용

- 미리보기를 요청번호·작성일·받는 업체/보내는 업소·납품·품목·소계·요청사항으로 구분한 흰 문서로 변경.
- 모바일은 읽기 쉬운 품목 행, PC와 공유 PDF는 표 형태로 표시.
- **PDF 파일 공유**를 모바일 주 버튼, 텍스트 공유를 보조 버튼으로 배치. 웹은 PDF 다운로드가 주 버튼.
- 수량 × 단가를 공통 계산해 품목 금액과 소계를 표시. 미입력 단가는 견적 요청으로 표시하고 합계에 포함하지 않으며 배송비·세금은 별도 확인 안내.
- 기존 PDF 미리보기·인쇄·사업자등록증 선택 첨부·계정 변경 보호·공유 후 상태 유지.

[사용법과 계산 기준](purchase-request-document-design.md). PDF 미리보기·파일 공유·인쇄는 기존 플러스/비즈니스 권한을 따른다. 선택한 등록증 사본만 문서에 포함한다. 실제 전송 확인·수락·입고 기록은 기존 수동 확인 절차를 유지한다.
