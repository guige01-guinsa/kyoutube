# 공급업체 등록·재료별 구매요청 초안

2026-09-15 구현·검증 및 승인된 DB0059/계정 삭제 함수/웹 운영 배포, v66 서명 AAB 생성 완료. [배포 기록](release-v66.md).

## 확정한 흐름

1. 로그인한 업체가 업체 소개와 취급 상품을 등록한다. 공개는 업체가 명시적으로 선택한다.
2. 구매자는 품목 대분류/소분류, 배송 지역, 원산지, 브랜드와 상품명으로 찾는다. 국산/수입은 품목 분류와 분리한다. 공개 업체를 선택하면 내 거래처에 등록하며, 이후 업체 선택에서는 해당 재료를 취급하는 내 거래처를 먼저 보여 준다. 같은 공개 업체를 다시 선택해도 중복 거래처를 만들지 않는다.
3. **재료마다 후보 업체를 최대 3곳** 선택한다. 전체 후보 업체 수를 3곳으로 제한하지 않는다. 같은 업체 상품은 재료당 하나를 선택한다.
4. 재료 선택 완료 후 최소 거래처 수 / 최저 구매가격 / 평점 우선 중 하나를 선택한다.
5. 선택한 후보 안에서 재료를 한 업체에 한 번씩 배정하고 업체별 초안을 만든다. 최종 사용자가 수량·상품·업체·납품 정보 등을 수정하고 저장한 뒤 기존 카카오톡 공유/웹 텍스트 복사/PDF 기능으로 전달한다. 초안 생성이나 공유창 열기를 발송 완료로 간주하지 않는다.

## 입력과 비교 기준

- 업체 필수: 업체명, 담당자, 공개 연락처, 소재 지역, 배송 가능 지역. 공개 전 취급 상품 1개 이상과 상품 이미지가 필요하다.
- 업체 선택: 상세 주소, 홈페이지/카카오 채널, 소개, 배송비, 무료배송 기준, 최소 주문금액. 미입력 배송비는 0원이 아닌 견적 필요다.
- 상품 필수: 상품명, 대/소분류, 대표 이미지, 판매 단위, 판매 단위당 내용량·내용 단위, 최소 구매 수량, 원산지 구분. 선택: 검색 별칭, 브랜드, 원산지 국가, 가격과 가격 유효일, 보관 방식, 상품 설명.
- 사용자가 입력한 구매 수량만 비교한다. 포장 내용량으로 구매 단위를 환산하고 포장 수를 올림한다. 환산 기준이 없으면 사용자가 직접 입력한다. 조리 수량이나 조리 재고를 자동 변경하지 않는다.
- 가격이 없거나 유효기간이 지난 상품, 배송비·세금이 불명확한 조합은 견적 필요로 표시한다. 다른 통화를 합산하지 않는다. 최소 주문 미달을 충족시키려고 요청하지 않은 재료를 자동 추가하지 않는다.
- 평점은 입고 확인한 구매자의 평가로 집계하며 업체 본인 평가는 차단한다. 평가 없음과 낮은 평점은 구분한다. 사업자 인증과 평점을 동일시하지 않는다.
- 조합이 많아 모든 조합을 비교하지 못한 경우 추천 결과임을 명시하고 전역 최저가/최소 거래처 보장을 주장하지 않는다.

## 범위

기존 개인 구매처·회원별 요청서 한도·수동 입고 기록을 유지한다. 공개 업체 등록이 유료 구매 권한을 부여하지 않는다. 결제 대행·자동 주문·자동 발송·조리 재고 차감은 추가하지 않는다.

## 권한과 자료 관리

- 공개 전 업체와 상품은 본인만 조회한다. 공개 업체·활성 상품은 로그인한 사용자가 찾을 수 있다. 공개 전 확인창에 공개할 연락처·주소·이미지 범위를 안내한다.
- 업체·상품 저장은 소유권과 수정 번호를 확인하는 RPC로 제한한다. 업체가 인증 배지를 스스로 설정하거나 타 업체 자료를 수정할 수 없다.
- 공개 업체 연결은 검증된 가져오기 RPC만 생성한다. 재선택 시 공개 연락처를 갱신하고 개인 메모·즐겨찾기는 유지한다. 거래처 삭제 후에도 이미 저장한 요청서의 업체 정보는 보존한다.
- 이미지는 비공개 Storage 버킷에 보관하고, 본인 또는 공개 상품에 대한 접근만 허용한다. JPG/PNG/WebP, 5MB, 업체당 상품 300개·계정당 업로드 600개 제한을 둔다. 취소·교체 이미지 정리는 최선 노력 방식이며, 계정 삭제 함수는 해당 계정의 남은 업로드까지 제거한다.
- 이미지 조회 주소는 15분 후 만료한다. 공개 중 발급된 주소와 내려받은 사본은 비공개 전환 즉시 회수되지 않는다.
- 가격과 활성 상태는 초안 계산 직전에 서버에서 다시 확인한다. 공유는 사용자가 최종 문서를 보고 실행한다. 공유창을 열었다고 발송 상태를 자동 변경하지 않는다.

## 운영 반영 — 승인 후 완료

1. 운영 DB에는 **0059_supplier_catalog_procurement.sql만** 명시적으로 적용한다. 미적용된 0057 사전 모집을 함께 적용하는 일괄 `db push`는 사용하지 않는다.
2. `delete-account` 함수 1개를 배포해 업체 이미지의 계정 삭제 처리를 연결한다.
3. 운영 웹을 빌드·배포하고 로그인/업체 등록 진입/카탈로그 접근을 점검한다. Android 앱도 같은 소스로 v66 서명 AAB를 생성·검증했다. Play 업로드·휴대폰 설치는 남아 있다.

로컬 DB 검사: `powershell -ExecutionPolicy Bypass -File tools/test/run_supplier_catalog_contract.ps1`. 기존 로컬 DB에 새 마이그레이션과 격리된 테스트 자료를 한 트랜잭션으로 넣어 검사한 뒤 모두 롤백한다. 운영 계정/자료를 사용하지 않는다.

## 화면에서 시작하는 위치

- 구매처 화면 하단 **공개 업체에서 내 거래처 선택** → 검색/분류 조건 → 내 거래처로 선택.
- 공급업체 찾기 화면의 검색창 위 **업체·상품 등록** → 업체 정보 입력 → 상품과 사진 등록 → 공개 확인. 업체 선택 중에도 표시하며 기존 등록자는 **내 업체·상품 관리**로 표시한다.
- 장보기 도우미의 **재료별 업체 선택 · 구매요청 초안** → 재료별 후보 최대 3곳 → 재료 선택 완료 → 기준 1개 선택 → 업체별 초안 수정·저장 → 미리보기·발송.
- 기존 요청서 편집의 **공개 업체에서 선택 · 내 거래처 등록**으로 업체 정보를 바로 채운다.
- 구매처 화면의 상단 더보기에서도 공개 업체 찾기, 재료별 초안 만들기, 내 업체 관리를 열 수 있다.
- 검색 조건은 처음부터 펼쳐 보여 주며, 필요하면 접어서 적용된 분류·지역·브랜드만 확인할 수 있다. 항목명은 입력칸과 분리한다. 화면 캡처의 업체/상품은 테스트 자료이며 실제 입점 업체가 아니다. [화면·공개 범위 보완](supplier-directory-ui.md).

## 남는 운영 확장

사업자 인증은 현재 서버 관리자만 부여할 수 있으며 서류 검토 업무 화면은 후속 범위다. 평점은 구매자의 수동 입고 확인에 기반하며 결제기관의 거래 인증은 아니다. 대량 조합은 탐색 폭을 제한한 추천임을 표시한다. 실제 업체와 구매자 계정의 사진 업로드·견적 확인·카카오톡 수신 검증은 운영 반영 후 별도로 수행해야 한다.

## 검증 기록

- 로컬 DB 계약 통과: 비공개 자료/이미지 접근 차단, 업체 소유권, 자기 인증 차단, 공개 전 이미지 필수, 잘못된 수량·가격 거절, 수정 충돌, 내 거래처 중복 방지/우선 표시, 개인 메모 보존, 연결값 위조 차단, 분류·지역·가격 필터, 요청서 연결/거래처 삭제 후 이력 보존, 입고 전·타인 평가 차단, 평점 중복 집계 방지, 가격 등록 후 통화 변경 차단. 검사 트랜잭션은 롤백했다.
- Deno `delete-account` 전체 타입 검사 통과, 업체 이미지 삭제의 범위·오류 처리 3개 검사 통과.
- v66 릴리스에서 전체 Flutter **342개 통과·기존 선택형 4개 건너뜀**. 앞서 관련 31개와 한영 캡처 검사도 통과했다.
- 최종 정적 분석 **0건**. 관련 31개에는 한영 번역, 기존 개인 거래처, 재료별 3곳 제한, 기준 선택 순서, 사용자 편집 후 저장, 저장 후 전달 상태 반영, 수량/포장/배송비/평점 비교, 100개 재료의 제한 탐색, 한영 화면 캡처 4개가 포함된다. 화면은 `.artifacts/supplier-directory-ko.png`, `supplier-directory-en.png`, `supplier-business-ko.png`, `supplier-business-en.png`로 확인했다.
- 운영 웹 빌드와 실제 공개 웹 8개·OAuth 연결 4개·신규 업체 화면 한영 로그인 보호 6개 검사 통과. DB0059·계정 삭제 함수·웹 배포와 v66 AAB 생성·검증 완료.
- `tools/dev/verify.ps1` 환경 확인에는 기존 PATH의 다른 SDK, Android 라이선스 상태 확인 불가, Visual Studio 설치 미완료 경고가 있다. 검사에는 프로젝트 고정 Flutter 3.44.8과 JDK 17을 사용했다.
