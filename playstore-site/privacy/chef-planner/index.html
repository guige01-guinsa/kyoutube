요리사 일정관리 개인정보처리방침

시행일: 2026년 10월 11일

요리사 일정관리는 레시피 스카우트의 업무·홍보 준비를 돕는 독립 일정관리 앱입니다. 이 방침은 현재 0.1 버전의 실제 동작을 기준으로 개인정보 처리 방식을 설명합니다.

1. 기기에 저장하는 정보

요리사 일정관리는 다음 정보를 사용자의 기기 또는 브라우저의 로컬 저장 공간에 저장합니다.

  • 사용자가 만든 일정, 업무 상태, 확인 항목, 실제 작업 시간
  • 알림 사용 선택과 기기 안에서 예약한 업무 알림
  • 레시피 스카우트 연결 요청 동의의 정책 번호와 동의 시각

2. 수집·공유·전송

현재 버전은 계정 가입, 로그인, 무료회원 자동 등록, 클라우드 동기화, 분석 도구, 광고 SDK를 제공하지 않습니다. 위 정보는 운영자나 제3자 서버로 전송·수집·공유하지 않습니다.

앱에서 레시피 스카우트 웹페이지를 여는 경우에는 해당 웹사이트로 이동하며, 이동한 뒤의 개인정보 처리는 레시피 스카우트 개인정보처리방침을 따릅니다.

3. 알림

사용자가 알림 권한을 허용한 경우에만 업무 시작 전 알림을 기기 안에 예약합니다. 알림 내용과 일정은 외부 서버로 보내지 않습니다.

4. 보관과 삭제

사용자는 앱 설정에서 이 기기의 체험 자료를 삭제할 수 있습니다. 삭제하면 일정, 업무 이력, 확인 항목, 실제 시간, 연결 요청 동의가 해당 기기 또는 브라우저에서 삭제됩니다.

현재 버전은 서버 계정을 만들거나 사용자 정보를 서버에 보관하지 않으므로 별도의 서버 계정 삭제 절차가 없습니다. 브라우저에서 사용한 경우 브라우저의 사이트 데이터 삭제로도 로컬 자료를 지울 수 있습니다.

5. 이용 대상

요리사 일정관리는 식당, 카페, 급식, 소규모 주방의 업무를 정리하려는 성인 사용자를 위한 앱입니다.

7. 방침 변경

계정, 서버 백업, 동기화, 분석, 광고 또는 외부 영상 게시 기능을 추가하기 전에 이 방침과 Google Play 데이터 안전성 정보를 갱신하고 앱 또는 웹사이트에서 안내합니다.
