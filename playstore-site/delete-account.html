playscout 계정 및 데이터 삭제 안내

playscout 사용자는 앱 안에서 직접 계정을 삭제할 수 있습니다. 계정 삭제 후에는 계정 복구가 어려울 수 있으므로 신중하게 진행해 주세요.

주의: 회원탈퇴를 진행하면 로그인 계정과 계정에 연결된 앱 데이터가 삭제 또는 비식별화됩니다. 삭제 완료 후에는 기존 계정으로 로그인할 수 없습니다.

1. 앱에서 계정 삭제하는 방법

  1. playscout 앱을 실행합니다.
  2. 계정에 로그인합니다.
  3. 홈 화면 상단의 계정 관리 아이콘을 선택합니다.
  4. 회원탈퇴 버튼을 선택합니다.
  5. 확인 창에서 탈퇴하기를 선택합니다.

2. 삭제되는 데이터

계정 삭제 시 다음 데이터가 삭제 또는 비식별화될 수 있습니다.

  • 로그인 계정 및 이메일 주소
  • 사용자가 만든 내 레시피
  • 레시피 재료, 조리 순서, 팁, 메모
  • 북마크 및 저장한 레시피 정보
  • 장보기 및 주방 관리 데이터
  • 사용자가 업로드한 이미지
  • 앱 사용과 연결된 사용자 설정

3. 보관될 수 있는 데이터

법령 준수, 보안, 부정 사용 방지, 장애 분석, 분쟁 대응을 위해 필요한 최소한의 로그는 최대 30일간 보관될 수 있으며, 이후 삭제 또는 비식별화됩니다.

4. 앱을 사용할 수 없는 경우
