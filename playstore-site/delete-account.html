PlayScout 계정 및 데이터 삭제 안내

PlayScout 사용자는 앱 안에서 직접 계정을 삭제할 수 있습니다. 계정 삭제가 완료되면 기존 계정으로 로그인할 수 없으며, 삭제된 데이터는 복구하기 어렵습니다.

주의: 회원탈퇴를 완료하면 계정과 계정에 연결된 앱 데이터가 삭제됩니다. 삭제 전에 필요한 레시피나 기록은 별도로 보관해 주세요.

1. 앱에서 계정 삭제하는 방법

  1. PlayScout 앱을 실행합니다.
  2. 삭제할 계정으로 로그인합니다.
  3. 홈 화면 상단의 계정 관리 아이콘을 선택합니다.
  4. 회원탈퇴 버튼을 선택합니다.
  5. 확인 창에서 탈퇴하기를 선택합니다.

2. 삭제되는 데이터

  • 로그인 계정 및 이메일 주소
  • 사용자가 만든 내 레시피, 재료, 조리 순서, 팁, 메모
  • 북마크 및 저장한 레시피 정보
  • 장보기 목록, 주방 관리 정보, 조리 기록
  • 사용자가 업로드한 레시피 이미지
  • 계정에 연결된 YouTube 레시피 메타데이터
  • AI feedback 및 계정에 연결된 AI 사용 기록
  • 기기 알림 token 삭제 시도

3. 공개 이미지와 캐시

공개 레시피에 사용된 이미지는 공개 URL을 통해 접근 가능할 수 있습니다. 계정 삭제 시 해당 계정에 연결된 업로드 이미지 파일을 삭제합니다.

다만 CDN 또는 브라우저 캐시로 인해 삭제 직후 일정 시간 동안 이전 이미지가 표시될 수 있습니다.

4. 보관될 수 있는 정보

법령 준수, 보안 사고 대응 또는 분쟁 처리 목적의 최소한의 서버 운영 로그는 관련 법령 및 서비스 운영 정책에 따라 별도로 보관될 수 있습니다. 이러한 로그는 계정 삭제 후 사용자 계정 정보와 직접 연결되지 않도록 처리합니다.
